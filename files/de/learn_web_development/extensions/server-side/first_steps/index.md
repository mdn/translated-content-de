In diesem Modul beantworten wir einige grundlegende Fragen zur serverseitigen Programmierung, etwa „Was ist das?“, „Wie unterscheidet sie sich von der clientseitigen Programmierung?“ und „Warum ist sie so nützlich?“. Außerdem geben wir einen Überblick über einige der beliebtesten serverseitigen Web-Frameworks und erläutern, wie Sie das am besten geeignete Framework für Ihr erstes Projekt auswählen. Abschließend bieten wir einen einführenden Überblick über die Sicherheit von Webservern.

## Voraussetzungen

Bevor Sie mit diesem Modul beginnen, benötigen Sie keine Kenntnisse in der serverseitigen Website-Programmierung oder einer anderen Art der Programmierung.

Sie sollten jedoch ein grundlegendes Verständnis davon haben, wie Websites und Webserver funktionieren. Dafür empfehlen wir folgende Lektüre:

- [Grundlegende Software installieren](/de/docs/Learn_web_development/Getting_started/Environment_setup/Installing_software)
- [Wie das Web funktioniert](/de/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works)
- [Ihre Website veröffentlichen](/de/docs/Learn_web_development/Getting_started/Your_first_website/Publishing_your_website)

Mit dem Grundverständnis, das Sie durch diese Vorbereitung gewinnen, können Sie die Module in diesem Abschnitt durcharbeiten.

## Tutorials

- [Einführung in die serverseitige Programmierung](/de/docs/Learn_web_development/Extensions/Server-side/First_steps/Introduction)
  - : Willkommen beim MDN-Einsteigerkurs zur serverseitigen Programmierung! Der erste Artikel betrachtet die serverseitige Programmierung aus übergeordneter Perspektive und beantwortet Fragen wie „Was ist das?“, „Wie unterscheidet sie sich von der clientseitigen Programmierung?“ und „Warum ist sie so nützlich?“. Danach werden Sie verstehen, welche zusätzlichen Möglichkeiten die serverseitige Programmierung Websites bietet.
- [Überblick über Client und Server](/de/docs/Learn_web_development/Extensions/Server-side/First_steps/Client-Server_overview)
  - : Nachdem Sie nun den Zweck und die möglichen Vorteile der serverseitigen Programmierung kennen, sehen wir uns an, was geschieht, wenn ein Server eine „dynamische Anfrage“ von einem Browser erhält. Da der serverseitige Code der meisten Websites Anfragen und Antworten auf ähnliche Weise verarbeitet, hilft Ihnen dies dabei zu verstehen, worauf es beim Schreiben Ihres eigenen Codes ankommt.
- [Serverseitige Web-Frameworks](/de/docs/Learn_web_development/Extensions/Server-side/First_steps/Web_frameworks)
  - : Im vorherigen Artikel wurde erklärt, was eine serverseitige Webanwendung tun muss, um auf Anfragen von Webbrowsern zu reagieren. Dieser Artikel erklärt, wie Web-Frameworks diese Aufgaben vereinfachen können, und hilft Ihnen, das richtige Framework für Ihre erste serverseitige Webanwendung auszuwählen.
- [Website-Sicherheit](/de/docs/Learn_web_development/Extensions/Server-side/First_steps/Website_security)
  - : Website-Sicherheit erfordert Aufmerksamkeit bei allen Aspekten der Erstellung und des Betriebs einer Website. Dieser einführende Artikel hilft Ihnen, die ersten wichtigen Schritte zu verstehen, mit denen Sie Ihre Webanwendung vor den häufigsten Bedrohungen schützen können.

> [!NOTE]
> Dieses Thema behandelt serverseitige Frameworks und deren Verwendung zum Erstellen von Websites. Wenn Sie Informationen zu clientseitigen JavaScript-Frameworks suchen, lesen Sie [Clientseitige JavaScript-Frameworks verstehen](/de/docs/Learn_web_development/Core/Frameworks_libraries).

## Lernkontrollen

Dieses Modul zu den ersten Schritten enthält keine Lernkontrolle, da wir Ihnen noch keinen Code gezeigt haben. An diesem Punkt sollten Sie ein allgemeines Verständnis dafür haben, welche Funktionen Sie mit serverseitiger Programmierung bereitstellen können, und entschieden haben, welches serverseitige Web-Framework Sie für Ihre erste serverseitige Anwendung verwenden möchten.
