Diese Seite enthält mehrere Tutorialreihen, die unterschiedliche Arbeitsabläufe zur Entwicklung verschiedener Arten von Webspielen vorstellen.

- [2D-Breakout-Spiel mit reinem JavaScript](/de/docs/Games/Tutorials/2D_breakout_game_pure_JavaScript)
  - : In diesem Schritt-für-Schritt-Tutorial implementieren Sie einen einfachen Breakout-Klon mit reinem JavaScript. Dabei lernen Sie die Grundlagen der Verwendung des {{htmlelement("canvas")}}-Elements kennen, um grundlegende Spielmechaniken wie das Rendern und Bewegen von Bildern, die Kollisionserkennung, Steuerungsmöglichkeiten sowie Gewinn- und Verlustzustände umzusetzen.
- [2D-Breakout-Spiel mit Phaser](/de/docs/Games/Tutorials/2D_breakout_game_Phaser)
  - : In diesem Schritt-für-Schritt-Tutorial implementieren Sie denselben Breakout-Klon wie in der vorherigen Tutorialreihe, diesmal jedoch mit dem HTML-Spieleframework [Phaser](https://phaser.io/). Dabei lernen Sie neben grundlegenden Spielmechaniken auch die Grundlagen und Vorteile der Arbeit mit Frameworks kennen.
- [2D-Labyrinthspiel mit Geräteausrichtung](/de/docs/Games/Tutorials/HTML5_Gamedev_Phaser_Device_Orientation)
  - : Dieses Tutorial zeigt, wie Sie mit HTML ein 2D-Labyrinthspiel erstellen. Dabei werden Grundlagen wie die Kollisionserkennung und das Platzieren von Sprites auf einem {{htmlelement("canvas")}} behandelt. Das mit dem Framework [Phaser](https://phaser.io/) entwickelte Mobilspiel nutzt die **APIs** für [Geräteausrichtung](/de/docs/Web/API/Device_orientation_events) und [Vibration](/de/docs/Web/API/Vibration_API), um das Spielerlebnis zu verbessern.
- [2D-Plattformspiel mit Phaser](https://mozdevs.github.io/html5-games-workshop/en/guides/platformer/start-here/)
  - : Diese Tutorialreihe zeigt, wie Sie mit [Phaser](https://phaser.io/) ein einfaches Plattformspiel erstellen. Sie behandelt Grundlagen wie Sprites, Kollisionen, Physik, sammelbare Gegenstände und mehr.
