Screenreader sind Softwareanwendungen, die versuchen, das auf einem Bildschirm Sichtbare auf nichtvisuelle Weise wiederzugeben, in der Regel als Text-zu-Sprache, aber auch in Brailleschrift oder durch Klangsymbole. Screenreader sind für Menschen mit Sehbehinderungen, Analphabetismus oder Lernbehinderungen unverzichtbar. Es gibt einige Screenreader als Browsererweiterungen, die meisten Screenreader funktionieren jedoch systemweit für alle Benutzeranwendungen, nicht nur für den Browser.

Im Hinblick auf die Web-{{Glossary("accessibility", "Barrierefreiheit")}} stellen die meisten User Agents ein Accessibility Object Model bereit, und Screenreader interagieren mit dedizierten Accessibility-APIs, wobei sie verschiedene Betriebssystemfunktionen nutzen und Hooking-Techniken einsetzen.

## Häufig verwendete Screenreader

### VoiceOver

iOS und macOS enthalten VoiceOver, einen integrierten Screenreader. Um auf macOS auf VoiceOver zuzugreifen, gehen Sie zu Systemeinstellungen > Bedienungshilfen > VoiceOver. Sie können VoiceOver auch mit fn + Command + F5 ein- und ausschalten. VoiceOver liest Inhalte sowohl vor als auch zeigt sie an. Der vorgelesene Inhalt wird in einem dunkelgrauen Feld angezeigt.

VoiceOver kann auch mit Befehlskürzeln verwendet werden. Eine vollständige Liste finden Sie unter [Allgemeine VoiceOver-Befehle auf dem Mac](https://support.apple.com/en-sg/guide/voiceover/cpvokys01/mac).

Weitere Informationen finden Sie im [VoiceOver-Benutzerhandbuch für Mac](https://support.apple.com/guide/voiceover/welcome/mac) und unter [VoiceOver in Apps auf dem iPhone verwenden](https://support.apple.com/guide/iphone/use-voiceover-in-apps-iphe4ee74be8/ios).

### Sprachausgabe

Die Sprachausgabe ist eine in Windows 10 und Windows 11 integrierte Screenreader-Anwendung.

Siehe [Vollständiger Leitfaden zur Sprachausgabe](https://support.microsoft.com/en-us/accessibility/windows/narrator/complete-guide-to-narrator).

### ChromeVox

Chromebooks verfügen über einen integrierten Screenreader namens ChromeVox, der Menschen mit Sehbehinderungen die Nutzung des Chrome-Betriebssystems ermöglicht.

Weitere Informationen finden Sie unter [ChromeVox-Screenreader](https://support.google.com/accessibility/answer/7031755).
