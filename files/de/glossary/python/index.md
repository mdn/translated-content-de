**Python** ist eine universelle Programmiersprache auf hohem Abstraktionsniveau. Sie verfolgt einen Multiparadigmenansatz, das heißt, sie unterstützt prozedurale, objektorientierte und einige funktionale Programmierkonstrukte.

Sie wurde von Guido van Rossum zwischen 1985 und 1990 als Nachfolgerin einer anderen Sprache (namens ABC) entwickelt und wird derzeit in einer Vielzahl von Bereichen wie Webentwicklung, Desktop-Anwendungen, Data Science, DevOps sowie Automatisierung/Produktivität eingesetzt.

Python wird unter einer von der OSI anerkannten Open-Source-Lizenz entwickelt, wodurch sie frei verwendet und verbreitet werden kann, auch für kommerzielle Zwecke. Die Lizenz von Python wird von der [Python Software Foundation](https://www.python.org/psf-landing/) verwaltet.
