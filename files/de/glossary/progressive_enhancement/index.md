**Progressive Enhancement** ist eine Gestaltungsphilosophie, die möglichst vielen Nutzern grundlegende Inhalte und Funktionen bereitstellt. Das bestmögliche Nutzungserlebnis erhalten darüber hinaus Nutzer moderner Browser, die den gesamten erforderlichen Code ausführen können.

_Progressive_ in _Progressive Enhancement_ bedeutet, eine Gestaltung zu schaffen, die Nutzern älterer Browser und Geräte mit eingeschränkten Fähigkeiten ein einfacheres, aber weiterhin nutzbares Erlebnis bietet. Zugleich **verbessert** sie das Nutzungserlebnis für Nutzer neuerer Browser und leistungsfähigerer Geräte hin zu einem ansprechenderen, umfassenderen Erlebnis.

Mit [Feature-Erkennung](/de/docs/Learn_web_development/Extensions/Testing/Feature_detection) wird in der Regel festgestellt, ob Browser modernere Funktionen unterstützen. {{Glossary("polyfill", "Polyfills")}} werden häufig verwendet, um fehlende Funktionen mit JavaScript zu ergänzen.

Besondere Aufmerksamkeit sollte der Barrierefreiheit gelten. Wo möglich, sollten geeignete Alternativen bereitgestellt werden.

Progressive Enhancement ist eine nützliche Technik, mit der sich Webentwickler auf die Entwicklung bestmöglicher Websites konzentrieren und zugleich sicherstellen können, dass diese auf verschiedenen, nicht im Voraus bekannten User Agents funktionieren. {{Glossary("Graceful_degradation", "Graceful Degradation")}} ist damit verwandt, aber nicht dasselbe. Der Ansatz wird oft als Gegenrichtung zu Progressive Enhancement betrachtet. Tatsächlich sind beide Ansätze sinnvoll und können sich häufig ergänzen.
