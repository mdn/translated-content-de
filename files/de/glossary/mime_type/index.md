Ein **MIME-Typ** (heute korrekt als „Medientyp“, manchmal aber auch als „Content-Type“ bezeichnet) ist eine Zeichenkette, die zusammen mit einer Datei gesendet wird und deren Typ angibt (sie beschreibt beispielsweise das Inhaltsformat: Eine Audiodatei könnte mit `audio/ogg` und eine Bilddatei mit `image/png` gekennzeichnet sein).

Er erfüllt denselben Zweck wie Dateinamenerweiterungen, die traditionell unter Windows verwendet werden.
Der Name stammt vom {{Glossary("mime", "MIME")}}-Standard, der ursprünglich in E-Mails verwendet wurde.
