Ein Fork ist eine Kopie eines vorhandenen Softwareprojekts, die zu einem bestimmten Zeitpunkt erstellt wird, um eigene Modifikationen zum Projekt hinzuzufügen.

Im Grunde genommen können Sie, wenn die Lizenz der Originalsoftware es erlaubt, den Code kopieren, um Ihre eigene Version davon zu entwickeln, mit Ihren eigenen Ergänzungen, was dann ein "Fork" ist.

Forks werden häufig in der Entwicklung von freier und Open-Source-Software gesehen. Dies ist nun ein bekannterer Begriff dank des Beitragsmodells, das Git (und/oder die GitHub-Plattform) verwendet.
