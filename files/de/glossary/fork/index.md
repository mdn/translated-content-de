Ein Fork ist eine Kopie eines bestehenden Softwareprojekts zu einem bestimmten Zeitpunkt, um dem Projekt eigene Änderungen hinzuzufügen.

Wenn die Lizenz der ursprünglichen Software dies erlaubt, können Sie den Code grundsätzlich kopieren, um eine eigene Version davon mit eigenen Ergänzungen zu entwickeln. Diese wird als „Fork“ bezeichnet.

Forks sind häufig in der Entwicklung freier und Open-Source-Software anzutreffen. Der Begriff ist durch das Beitragsmodell mit Git (und/oder der GitHub-Plattform) inzwischen populärer geworden.
