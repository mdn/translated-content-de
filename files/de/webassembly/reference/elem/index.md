Dieses Set von Seiten beschreibt die verfügbaren Anweisungen in Wasm in Bezug auf [elem](/de/docs/WebAssembly/Reference/Definitions/elem)-Definitionen.

- [`elem.drop`](/de/docs/WebAssembly/Reference/Elem/drop)
  - : Verwirft die Daten, die von einem [passiven](/de/docs/WebAssembly/Reference/Definitions/elem#passive_form) `elem`-Segment enthalten sind, und gibt dessen Speicher frei, nachdem es in einer [`table.init`](/de/docs/WebAssembly/Reference/Table/init) verwendet wurde.
