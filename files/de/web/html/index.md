**HTML** (HyperText Markup Language) ist der grundlegendste Baustein des Webs. Es definiert die Bedeutung und Struktur von Webinhalten. Andere Technologien als HTML werden im Allgemeinen verwendet, um das Erscheinungsbild/die Darstellung einer Webseite ([CSS](/de/docs/Web/CSS)) oder ihre Funktionalität/ihr Verhalten ([JavaScript](/de/docs/Web/JavaScript)) zu beschreiben.

„Hypertext“ bezeichnet Text, der Links enthält, welche Webseiten miteinander verbinden – entweder innerhalb einer einzelnen Website oder zwischen Websites. Links sind ein grundlegender Aspekt des Webs. Indem Sie Inhalte ins Internet hochladen und mit Seiten verlinken, die von anderen Personen erstellt wurden, werden Sie zu einem aktiven Teilnehmenden am World Wide Web.

HTML verwendet „Markup“, um Text, Bilder und andere Inhalte für die Darstellung in einem Webbrowser auszuzeichnen. HTML-Markup umfasst spezielle „Elemente“ wie {{HTMLElement("head")}}, {{HTMLElement("title")}}, {{HTMLElement("body")}}, {{HTMLElement("header")}}, {{HTMLElement("footer")}}, {{HTMLElement("article")}}, {{HTMLElement("section")}}, {{HTMLElement("p")}}, {{HTMLElement("div")}}, {{HTMLElement("span")}}, {{HTMLElement("img")}}, {{HTMLElement("aside")}}, {{HTMLElement("audio")}}, {{HTMLElement("canvas")}}, {{HTMLElement("datalist")}}, {{HTMLElement("details")}}, {{HTMLElement("embed")}}, {{HTMLElement("nav")}}, {{HTMLElement("search")}}, {{HTMLElement("output")}}, {{HTMLElement("progress")}}, {{HTMLElement("video")}}, {{HTMLElement("ul")}}, {{HTMLElement("ol")}}, {{HTMLElement("li")}} und viele weitere.

Ein HTML-Element wird durch „Tags“ von anderem Text in einem Dokument abgegrenzt. Diese bestehen aus dem Elementnamen, der von `<` und `>` umgeben ist. Beim Namen eines Elements innerhalb eines Tags wird nicht zwischen Groß- und Kleinschreibung unterschieden. Das heißt, er kann in Großbuchstaben, Kleinbuchstaben oder einer Mischung aus beiden geschrieben werden. Beispielsweise kann der `<title>`-Tag als `<Title>`, `<TITLE>` oder auf jede andere Weise geschrieben werden. Die Konvention und empfohlene Praxis ist jedoch, Tags kleingeschrieben zu verwenden.

Die folgenden Artikel können Ihnen helfen, mehr über HTML zu erfahren.

## Referenz

HTML besteht aus **Elementen**, die jeweils durch eine beliebige Anzahl von **Attributen** verändert werden können. HTML-Dokumente sind über **Links** miteinander verbunden. Durchsuchen Sie die vollständige Dokumentation der [HTML-Referenz](/de/docs/Web/HTML/Reference).

- [HTML-Elemente](/de/docs/Web/HTML/Reference/Elements)
  - : Referenz für alle HTML-{{Glossary("Element", "Elemente")}}.
- [HTML-Attribute](/de/docs/Web/HTML/Reference/Attributes)
  - : Referenz für alle HTML-Attribute. Attribute sind zusätzliche Werte, die Elemente konfigurieren oder ihr Verhalten auf verschiedene Weise anpassen.
- [Globale Attribute](/de/docs/Web/HTML/Reference/Global_attributes)
  - : Referenz für globale Attribute, die bei allen HTML-Elementen angegeben werden können, _selbst bei solchen, die nicht im Standard festgelegt sind_. Das bedeutet, dass alle nicht standardmäßigen Elemente diese Attribute dennoch erlauben müssen, obwohl diese Elemente das Dokument nicht HTML5-konform machen.

### Attribute nach Element

- [Input-Typen](/de/docs/Web/HTML/Reference/Elements/input)
  - : Werden verwendet, um interaktive Steuerelemente für webbasierte Formulare zu erstellen.
- [Script-Typen](/de/docs/Web/HTML/Reference/Elements/script/type)
  - : Gibt den Typ des durch das Element dargestellten Scripts an.
- [meta name](/de/docs/Web/HTML/Reference/Elements/meta/name)
  - : Stellt Metadaten in Name-Wert-Paaren für die gesamte Seite bereit.

### Attributwerte

- [rel-Schlüsselwörter](/de/docs/Web/HTML/Reference/Attributes/rel)
  - : Definiert die Beziehung zwischen einer verlinkten Ressource und dem aktuellen Dokument.
