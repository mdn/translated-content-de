Diese Seite führt alle {{Glossary("HTML", "HTML-")}}{{Glossary("Element", "Elemente")}} auf, die mithilfe von {{Glossary("Tag", "Tags")}} erstellt werden.

Sie sind nach Funktion gruppiert, damit Sie leicht finden können, wonach Sie suchen. Eine alphabetische Liste aller Elemente finden Sie in der Seitenleiste auf der Seite jedes Elements sowie auf dieser Seite.

> [!NOTE]
> Weitere Informationen zu den Grundlagen von HTML-Elementen und -Attributen finden Sie unter [Anatomie eines HTML-Elements](/de/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax#anatomy_of_an_html_element).

## Hauptelement

| Element                 | Beschreibung                                                                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| {{HTMLElement("html")}} | Repräsentiert die Wurzel (das Element der obersten Ebene) eines HTML-Dokuments und wird daher auch als _Wurzelelement_ bezeichnet. Alle anderen Elemente müssen Nachfahren dieses Elements sein. |

## Dokumentmetadaten

Metadaten enthalten Informationen über die Seite. Dazu gehören Informationen über Styles, Skripte und Daten, die Software ({{Glossary("search_engine", "Suchmaschinen")}}, {{Glossary("Browser", "Browser")}} usw.) beim Verwenden und Rendern der Seite unterstützen. Metadaten für Styles und Skripte können auf der Seite definiert oder mit einer anderen Datei verknüpft werden, die diese Informationen enthält.

| Element                  | Beschreibung                                                                                                                                                                                                                                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("base")}}  | Gibt die Basis-URL an, die für alle relativen URLs in einem Dokument verwendet werden soll. In einem Dokument kann es nur ein solches Element geben.                                                                                                                                                                    |
| {{HTMLElement("head")}}  | Enthält maschinenlesbare Informationen (Metadaten) über das Dokument, etwa seinen [Titel](/de/docs/Web/HTML/Reference/Elements/title), [Skripte](/de/docs/Web/HTML/Reference/Elements/script) und [Stylesheets](/de/docs/Web/HTML/Reference/Elements/style).                                                            |
| {{HTMLElement("link")}}  | Gibt Beziehungen zwischen dem aktuellen Dokument und einer externen Ressource an. Dieses Element wird am häufigsten zur Verknüpfung mit CSS verwendet, dient aber unter anderem auch zum Festlegen von Website-Icons (sowohl Icons im „Favicon“-Stil als auch Icons für den Startbildschirm und Apps auf Mobilgeräten). |
| {{HTMLElement("meta")}}  | Repräsentiert {{Glossary("Metadata", "Metadaten")}}, die nicht durch andere metadatenbezogene HTML-Elemente wie {{HTMLElement("base")}}, {{HTMLElement("link")}}, {{HTMLElement("script")}}, {{HTMLElement("style")}} und {{HTMLElement("title")}} dargestellt werden können.                                           |
| {{HTMLElement("style")}} | Enthält Style-Informationen für ein Dokument oder einen Teil eines Dokuments. Es enthält CSS, das auf den Inhalt des Dokuments angewendet wird, das dieses Element enthält.                                                                                                                                             |
| {{HTMLElement("title")}} | Definiert den Titel des Dokuments, der in der Titelleiste eines {{Glossary("Browser", "Browsers")}} oder im Tab einer Seite angezeigt wird. Es enthält nur Text; HTML-Tags innerhalb des Elements werden, falls vorhanden, ebenfalls als Klartext behandelt.                                                            |

## Wurzelelement für Abschnittsbildung

| Element                 | Beschreibung                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("body")}} | Repräsentiert den Inhalt eines HTML-Dokuments. In einem Dokument kann es nur ein solches Element geben. |

## Inhaltsabschnitte

Elemente zur Inhaltsabschnittsbildung ermöglichen es Ihnen, den Dokumentinhalt in logische Teile zu gliedern. Verwenden Sie die Elemente zur Abschnittsbildung, um eine grobe Gliederung Ihres Seiteninhalts zu erstellen, einschließlich Header- und Footer-Navigation sowie Überschriftenelementen zur Kennzeichnung von Inhaltsabschnitten.

| Element                                                                                                                                                                                                                                                                                                                                                                                              | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("address")}}                                                                                                                                                                                                                                                                                                                                                                           | Gibt an, dass das eingeschlossene HTML Kontaktinformationen für eine Person oder mehrere Personen beziehungsweise für eine Organisation bereitstellt.                                                                                                                                                                                                                                                                                                   |
| {{HTMLElement("article")}}                                                                                                                                                                                                                                                                                                                                                                           | Repräsentiert eine eigenständige Zusammenstellung in einem Dokument, einer Seite, einer Anwendung oder Website, die zur unabhängigen Verteilung oder Wiederverwendung bestimmt ist (z. B. bei Syndication). Beispiele sind ein Forenbeitrag, ein Zeitschriften- oder Zeitungsartikel, ein Blogbeitrag, eine Produktkarte, ein von Nutzenden eingereichter Kommentar, ein interaktives Widget oder Gadget oder jede andere eigenständige Inhaltseinheit. |
| {{HTMLElement("aside")}}                                                                                                                                                                                                                                                                                                                                                                             | Repräsentiert einen Teil eines Dokuments, dessen Inhalt nur indirekt mit dem Hauptinhalt des Dokuments zusammenhängt. Asides werden häufig als Seitenleisten oder Hinweisboxen dargestellt.                                                                                                                                                                                                                                                             |
| {{HTMLElement("footer")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert einen Footer für sein nächstes Vorfahrenelement mit [Abschnittsinhalt](/de/docs/Web/HTML/Guides/Content_categories#sectioning_content) oder [Wurzelelement für Abschnittsbildung](/de/docs/Web/HTML/Reference/Elements/Heading_Elements). Ein `<footer>` enthält typischerweise Informationen über den Autor des Abschnitts, Urheberrechtsdaten oder Links zu verwandten Dokumenten.                                                      |
| {{HTMLElement("header")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert einleitenden Inhalt, typischerweise eine Gruppe einleitender oder navigationsbezogener Hilfsmittel. Es kann einige Überschriftenelemente, aber auch ein Logo, ein Suchformular, einen Autorennamen und andere Elemente enthalten.                                                                                                                                                                                                         |
| [`<h1>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h2>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h3>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h4>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h5>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h6>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements) | Repräsentieren sechs Ebenen von Abschnittsüberschriften. `<h1>` ist die höchste Abschnittsebene und `<h6>` die niedrigste.                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("hgroup")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert eine Überschrift, die mit sekundärem Inhalt wie Unterüberschriften, einem alternativen Titel oder einer Tagline gruppiert ist.                                                                                                                                                                                                                                                                                                            |
| {{HTMLElement("main")}}                                                                                                                                                                                                                                                                                                                                                                              | Repräsentiert den dominierenden Inhalt des Body eines Dokuments. Der Hauptinhaltsbereich besteht aus Inhalt, der direkt mit dem zentralen Thema eines Dokuments oder der zentralen Funktionalität einer Anwendung zusammenhängt oder diese erweitert.                                                                                                                                                                                                   |
| {{HTMLElement("nav")}}                                                                                                                                                                                                                                                                                                                                                                               | Repräsentiert einen Abschnitt einer Seite, dessen Zweck darin besteht, Navigationslinks bereitzustellen, entweder innerhalb des aktuellen Dokuments oder zu anderen Dokumenten. Häufige Beispiele für Navigationsabschnitte sind Menüs, Inhaltsverzeichnisse und Indizes.                                                                                                                                                                               |
| {{HTMLElement("section")}}                                                                                                                                                                                                                                                                                                                                                                           | Repräsentiert einen generischen eigenständigen Abschnitt eines Dokuments, für den es kein spezifischeres semantisches Element gibt. Abschnitte sollten, mit sehr wenigen Ausnahmen, immer eine Überschrift haben.                                                                                                                                                                                                                                       |
| {{HTMLElement("search")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert einen Teil, der eine Gruppe von Formularsteuerelementen oder anderen Inhalt enthält, die mit der Durchführung einer Such- oder Filteroperation zusammenhängen.                                                                                                                                                                                                                                                                            |

## Textinhalt

Verwenden Sie HTML-Textinhaltselemente, um Blöcke oder Abschnitte von Inhalt zu organisieren, die zwischen den öffnenden {{HTMLElement("body")}}- und schließenden `</body>`-Tags platziert sind. Diese Elemente sind wichtig für {{Glossary("accessibility", "Barrierefreiheit")}} und {{Glossary("SEO", "SEO")}} und kennzeichnen den Zweck oder die Struktur dieses Inhalts.

| Element                       | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("blockquote")}} | Gibt an, dass der eingeschlossene Text ein längeres Zitat ist. Üblicherweise wird dies visuell durch Einrückung dargestellt. Eine URL für die Quelle des Zitats kann mit dem Attribut `cite` angegeben werden, während eine Textdarstellung der Quelle mit dem Element {{HTMLElement("cite")}} angegeben werden kann.                                                                                                                                                                               |
| {{HTMLElement("dd")}}         | Stellt die Beschreibung, Definition oder den Wert für den vorangehenden Begriff ({{HTMLElement("dt")}}) in einer Beschreibungsliste ({{HTMLElement("dl")}}) bereit.                                                                                                                                                                                                                                                                                                                                 |
| {{HTMLElement("div")}}        | Der generische Container für Flow-Inhalt. Er hat keine Auswirkung auf den Inhalt oder das Layout, bis er auf irgendeine Weise mit CSS gestaltet wird (z. B. indem Styling direkt darauf angewendet wird oder auf sein Elternelement ein Layoutmodell wie {{Glossary("Flexbox", "Flexbox")}} angewendet wird).                                                                                                                                                                                       |
| {{HTMLElement("dl")}}         | Repräsentiert eine Beschreibungsliste. Das Element umfasst eine Liste von Gruppen aus Begriffen (angegeben durch das Element {{HTMLElement("dt")}}) und Beschreibungen (bereitgestellt durch {{HTMLElement("dd")}}-Elemente). Häufige Verwendungen dieses Elements sind die Implementierung eines Glossars oder die Anzeige von Metadaten (einer Liste von Schlüssel-Wert-Paaren).                                                                                                                  |
| {{HTMLElement("dt")}}         | Gibt einen Begriff in einer Beschreibungs- oder Definitionsliste an und muss daher innerhalb eines Elements {{HTMLElement("dl")}} verwendet werden. Darauf folgt üblicherweise ein Element {{HTMLElement("dd")}}; mehrere aufeinanderfolgende `<dt>`-Elemente geben jedoch mehrere Begriffe an, die alle durch das unmittelbar folgende Element {{HTMLElement("dd")}} definiert werden.                                                                                                             |
| {{HTMLElement("figcaption")}} | Repräsentiert eine Beschriftung oder Legende, die den restlichen Inhalt seines übergeordneten Elements {{HTMLElement("figure")}} beschreibt.                                                                                                                                                                                                                                                                                                                                                        |
| {{HTMLElement("figure")}}     | Repräsentiert eigenständigen Inhalt, möglicherweise mit einer optionalen Beschriftung, die durch das Element {{HTMLElement("figcaption")}} angegeben wird. Die Abbildung, ihre Beschriftung und ihr Inhalt werden als eine Einheit referenziert.                                                                                                                                                                                                                                                    |
| {{HTMLElement("hr")}}         | Repräsentiert eine thematische Trennung zwischen Elementen auf Absatzebene: beispielsweise einen Szenenwechsel in einer Geschichte oder einen Themenwechsel innerhalb eines Abschnitts.                                                                                                                                                                                                                                                                                                             |
| {{HTMLElement("li")}}         | Repräsentiert ein Element in einer Liste. Es muss in einem Elternelement enthalten sein: einer geordneten Liste ({{HTMLElement("ol")}}), einer ungeordneten Liste ({{HTMLElement("ul")}}) oder einem Menü ({{HTMLElement("menu")}}). In Menüs und ungeordneten Listen werden Listenelemente üblicherweise mit Aufzählungszeichen dargestellt. In geordneten Listen werden sie üblicherweise mit einem aufsteigenden Zähler auf der linken Seite dargestellt, etwa einer Zahl oder einem Buchstaben. |
| {{HTMLElement("menu")}}       | Eine semantische Alternative zu {{HTMLElement("ul")}}, die von Browsern (und im Barrierefreiheitsbaum) jedoch nicht anders als {{HTMLElement("ul")}} behandelt wird. Es repräsentiert eine ungeordnete Liste von Elementen (die durch {{HTMLElement("li")}}-Elemente repräsentiert werden).                                                                                                                                                                                                         |
| {{HTMLElement("ol")}}         | Repräsentiert eine geordnete Liste von Elementen — üblicherweise als nummerierte Liste dargestellt.                                                                                                                                                                                                                                                                                                                                                                                                 |
| {{HTMLElement("p")}}          | Repräsentiert einen Absatz. Absätze werden in visuellen Medien üblicherweise als Textblöcke dargestellt, die durch Leerzeilen und/oder Einrückung der ersten Zeile von benachbarten Blöcken getrennt sind, HTML-Absätze können jedoch jede strukturelle Gruppierung zusammenhängender Inhalte sein, etwa Bilder oder Formularfelder.                                                                                                                                                                |
| {{HTMLElement("pre")}}        | Repräsentiert vorformatierten Text, der genau so dargestellt werden soll, wie er in der HTML-Datei geschrieben ist. Der Text wird üblicherweise mit einer nichtproportionalen oder [Monospace-](<(https://en.wikipedia.org/wiki/Monospaced_font)>)Schriftart dargestellt. Leerraum innerhalb dieses Elements wird wie geschrieben angezeigt.                                                                                                                                                        |
| {{HTMLElement("ul")}}         | Repräsentiert eine ungeordnete Liste von Elementen, die üblicherweise als Aufzählungsliste dargestellt wird.                                                                                                                                                                                                                                                                                                                                                                                        |

## Semantik von Inline-Text

Verwenden Sie die HTML-Semantik für Inline-Text, um die Bedeutung, Struktur oder den Stil eines Worts, einer Zeile oder eines beliebigen Textausschnitts zu definieren.

| Element                   | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("a")}}      | Erstellt zusammen mit seinem Attribut `href` einen Hyperlink zu Webseiten, Dateien, E-Mail-Adressen, Positionen innerhalb der aktuellen Seite oder allem anderen, das durch eine URL adressiert werden kann.                                                                                                                                                                                                                                                                                                                                                                                                  |
| {{HTMLElement("abbr")}}   | Repräsentiert eine Abkürzung oder ein Akronym.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("b")}}      | Wird verwendet, um die Aufmerksamkeit der Lesenden auf den Inhalt des Elements zu lenken, dem ansonsten keine besondere Wichtigkeit zukommt. Es war früher als Boldface-Element bekannt, und die meisten Browser stellen den Text weiterhin fett dar. Sie sollten `<b>` jedoch nicht verwenden, um Text zu gestalten oder ihm Wichtigkeit zu verleihen. Wenn Sie fetten Text erstellen möchten, sollten Sie die CSS-Eigenschaft {{cssxref("font-weight")}} verwenden. Wenn Sie angeben möchten, dass ein Element von besonderer Wichtigkeit ist, sollten Sie das Element {{HTMLElement("strong")}} verwenden. |
| {{HTMLElement("bdi")}}    | Weist den bidirektionalen Algorithmus des Browsers an, den enthaltenen Text isoliert von seinem umgebenden Text zu behandeln. Dies ist besonders nützlich, wenn eine Website dynamisch Text einfügt und die Schreibrichtung des eingefügten Texts nicht kennt.                                                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("bdo")}}    | Überschreibt die aktuelle Schreibrichtung von Text, sodass der darin enthaltene Text in einer anderen Richtung dargestellt wird.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("br")}}     | Erzeugt einen Zeilenumbruch im Text (Wagenrücklauf). Dies ist nützlich, um ein Gedicht oder eine Adresse zu schreiben, bei denen die Aufteilung in Zeilen von Bedeutung ist.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| {{HTMLElement("cite")}}   | Wird verwendet, um den Titel eines kreativen Werks auszuzeichnen. Die Referenz kann gemäß kontextgerechten Konventionen für Zitiermetadaten in abgekürzter Form erfolgen.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| {{HTMLElement("code")}}   | Zeigt seinen Inhalt in einem Stil an, der darauf hinweist, dass der Text ein kurzes Fragment von Computercode ist. Standardmäßig wird der Inhaltstext mit der Standard-Monospace-Schriftart des User Agents angezeigt.                                                                                                                                                                                                                                                                                                                                                                                        |
| {{HTMLElement("data")}}   | Verknüpft einen gegebenen Inhalt mit einer maschinenlesbaren Übersetzung. Wenn der Inhalt zeit- oder datumsbezogen ist, muss das Element `<time>` verwendet werden.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| {{HTMLElement("dfn")}}    | Wird verwendet, um den Begriff anzugeben, der im Kontext einer Definitionsphrase oder eines Definitionssatzes definiert wird. Das Vorfahrenelement {{HTMLElement("p")}}, die Paarung aus {{HTMLElement("dt")}}/{{HTMLElement("dd")}} oder der nächste Abschnittsvorfahr des Elements `<dfn>` wird als Definition des Begriffs betrachtet.                                                                                                                                                                                                                                                                     |
| {{HTMLElement("em")}}     | Kennzeichnet Text mit Betonung. Das Element `<em>` kann verschachtelt werden, wobei jede Verschachtelungsebene einen höheren Grad an Betonung anzeigt.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| {{HTMLElement("i")}}      | Repräsentiert einen Textbereich, der aus irgendeinem Grund vom normalen Text abgesetzt ist, etwa idiomatischen Text, Fachbegriffe und taxonomische Bezeichnungen. Historisch wurden diese kursiv dargestellt, was der ursprüngliche Grund für die Benennung dieses Elements als `<i>` ist.                                                                                                                                                                                                                                                                                                                    |
| {{HTMLElement("kbd")}}    | Repräsentiert eine Spanne von Inline-Text, die eine Texteingabe des Benutzers über eine Tastatur, Spracheingabe oder ein anderes Texteingabegerät bezeichnet. Konventionell stellt der User Agent den Inhalt eines `<kbd>`-Elements standardmäßig mit seiner Standard-Monospace-Schriftart dar, obwohl dies nicht durch den HTML-Standard vorgeschrieben ist.                                                                                                                                                                                                                                                 |
| {{HTMLElement("mark")}}   | Repräsentiert Text, der aufgrund der Relevanz der markierten Passage im umgebenden Kontext zu Referenz- oder Notationszwecken markiert oder hervorgehoben ist.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("q")}}      | Gibt an, dass der eingeschlossene Text ein kurzes Inline-Zitat ist. Die meisten modernen Browser implementieren dies, indem sie den Text mit Anführungszeichen umgeben. Dieses Element ist für kurze Zitate gedacht, die keine Absatzumbrüche erfordern; verwenden Sie für lange Zitate das Element {{HTMLElement("blockquote")}}.                                                                                                                                                                                                                                                                            |
| {{HTMLElement("rp")}}     | Wird verwendet, um Ersatzklammern für Browser bereitzustellen, die die Anzeige von Ruby-Anmerkungen mithilfe des Elements {{HTMLElement("ruby")}} nicht unterstützen. Ein `<rp>`-Element sollte jede öffnende und schließende Klammer umschließen, die das Element {{HTMLElement("rt")}} umgibt, das den Text der Anmerkung enthält.                                                                                                                                                                                                                                                                          |
| {{HTMLElement("rt")}}     | Gibt die Ruby-Textkomponente einer Ruby-Anmerkung an, die Informationen zur Aussprache, Übersetzung oder Transkription für ostasiatische Typografie bereitstellt. Das Element `<rt>` muss immer innerhalb eines Elements {{HTMLElement("ruby")}} enthalten sein.                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("ruby")}}   | Repräsentiert kleine Anmerkungen, die über, unter oder neben Basistexte gerendert werden und normalerweise zur Anzeige der Aussprache ostasiatischer Zeichen verwendet werden. Es kann auch verwendet werden, um andere Textarten zu annotieren, aber diese Verwendung ist weniger verbreitet.                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("s")}}      | Stellt Text durchgestrichen oder mit einer Linie dar. Verwenden Sie das Element `<s>`, um Dinge darzustellen, die nicht mehr relevant oder nicht mehr korrekt sind. `<s>` ist jedoch nicht geeignet, um Dokumentbearbeitungen anzugeben; verwenden Sie dafür je nach Bedarf die Elemente {{HTMLElement("del")}} und {{HTMLElement("ins")}}.                                                                                                                                                                                                                                                                   |
| {{HTMLElement("samp")}}   | Wird verwendet, um Inline-Text zu umschließen, der eine Beispielausgabe (oder zitierte Ausgabe) eines Computerprogramms repräsentiert. Sein Inhalt wird üblicherweise mit der Standard-Monospace-Schriftart des Browsers dargestellt (etwa [Courier](<https://en.wikipedia.org/wiki/Courier_(typeface)>) oder Lucida Console).                                                                                                                                                                                                                                                                                |
| {{HTMLElement("small")}}  | Repräsentiert Nebenbemerkungen und Kleingedrucktes, etwa Urheberrechts- und Rechtstexte, unabhängig von seiner gestylten Darstellung. Standardmäßig wird der darin enthaltene Text eine Schriftgröße kleiner dargestellt, etwa von `small` zu `x-small`.                                                                                                                                                                                                                                                                                                                                                      |
| {{HTMLElement("span")}}   | Ein generischer Inline-Container für Phrasing-Inhalt, der von sich aus nichts repräsentiert. Er kann verwendet werden, um Elemente zu Styling-Zwecken (mithilfe der Attribute `class` oder `id`) zu gruppieren oder weil sie Attributwerte wie `lang` gemeinsam haben. Er sollte nur verwendet werden, wenn kein anderes semantisches Element geeignet ist. `<span>` ähnelt stark einem div-Element, aber div ist ein {{Glossary("Block-level_content", "Element auf Blockebene")}}, während ein `<span>` ein {{Glossary("Inline-level_content", "Element auf Inline-Ebene")}} ist.                           |
| {{HTMLElement("strong")}} | Gibt an, dass sein Inhalt starke Wichtigkeit, Ernsthaftigkeit oder Dringlichkeit hat. Browser stellen den Inhalt üblicherweise in Fettschrift dar.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| {{HTMLElement("sub")}}    | Gibt Inline-Text an, der aus rein typografischen Gründen tiefgestellt angezeigt werden soll. Tiefstellungen werden üblicherweise mit einer abgesenkten Grundlinie und kleinerem Text dargestellt.                                                                                                                                                                                                                                                                                                                                                                                                             |
| {{HTMLElement("sup")}}    | Gibt Inline-Text an, der aus rein typografischen Gründen hochgestellt angezeigt werden soll. Hochstellungen werden üblicherweise mit einer angehobenen Grundlinie und kleinerem Text dargestellt.                                                                                                                                                                                                                                                                                                                                                                                                             |
| {{HTMLElement("time")}}   | Repräsentiert einen bestimmten Zeitraum. Es kann das Attribut `datetime` enthalten, um Datumsangaben in ein maschinenlesbares Format zu übersetzen und damit bessere Suchmaschinenergebnisse oder benutzerdefinierte Funktionen wie Erinnerungen zu ermöglichen.                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("u")}}      | Repräsentiert eine Spanne von Inline-Text, die auf eine Weise dargestellt werden soll, die angibt, dass sie eine nichttextuelle Anmerkung hat. Standardmäßig wird dies als einzelne durchgehende Unterstreichung dargestellt, kann aber mit CSS geändert werden.                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("var")}}    | Repräsentiert den Namen einer Variable in einem mathematischen Ausdruck oder einem Programmierkontext. Er wird üblicherweise mit einer kursiven Variante der aktuellen Schriftart dargestellt, obwohl dieses Verhalten browserabhängig ist.                                                                                                                                                                                                                                                                                                                                                                   |
| {{HTMLElement("wbr")}}    | Repräsentiert eine mögliche Wortumbruchstelle — eine Position innerhalb eines Texts, an der der Browser optional eine Zeile umbrechen kann, obwohl seine Regeln für Zeilenumbrüche an dieser Stelle sonst keinen Umbruch erzeugen würden.                                                                                                                                                                                                                                                                                                                                                                     |

## Bilder und Multimedia

HTML unterstützt verschiedene Multimediaressourcen wie Bilder, Audio und Video.

| Element                  | Beschreibung                                                                                                                                                                                                                                                                                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("area")}}  | Definiert einen Bereich innerhalb einer Image Map mit vordefinierten anklickbaren Bereichen. Eine _Image Map_ ermöglicht es, geometrische Bereiche eines Bildes mit einem {{Glossary("Hyperlink", "Hyperlink")}} zu verknüpfen.                                                                                                                            |
| {{HTMLElement("audio")}} | Wird verwendet, um Audioinhalte in Dokumente einzubetten. Es kann eine oder mehrere Audioquellen enthalten, die mithilfe des Attributs `src` oder des Source-Elements repräsentiert werden: Der Browser wählt die am besten geeignete aus. Es kann auch das Ziel für gestreamte Medien sein, mithilfe eines [`MediaStream`](/de/docs/Web/API/MediaStream). |
| {{HTMLElement("img")}}   | Bettet ein Bild in das Dokument ein.                                                                                                                                                                                                                                                                                                                       |
| {{HTMLElement("map")}}   | Wird zusammen mit {{HTMLElement("area")}}-Elementen verwendet, um eine Image Map (einen anklickbaren Linkbereich) zu definieren.                                                                                                                                                                                                                           |
| {{HTMLElement("track")}} | Wird als Kind der Medienelemente audio und video verwendet. ## Web Components

Web Components ist eine HTML-bezogene Technologie, die es im Wesentlichen ermöglicht, benutzerdefinierte Elemente zu erstellen und zu verwenden, als wären sie reguläres HTML. Außerdem können Sie benutzerdefinierte Versionen von Standard-HTML-Elementen erstellen.

| Element                     | Beschreibung                                                                                                                                                                                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| {{HTMLElement("slot")}}     | Als Teil der Technologie-Suite [Web Components](/de/docs/Web/API/Web_components) ist dieses Element ein Platzhalter innerhalb einer Webkomponente, den Sie mit Ihrem eigenen Markup füllen können. So können Sie getrennte DOM-Bäume erstellen und gemeinsam darstellen. |
| {{HTMLElement("template")}} | Ein Mechanismus zum Speichern von HTML, das beim Laden einer Seite nicht sofort gerendert werden soll, aber anschließend während der Laufzeit mithilfe von JavaScript instanziiert werden kann.                                                                          |
