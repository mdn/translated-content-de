Diese Seite listet alle {{Glossary("HTML", "HTML")}}-{{Glossary("Element", "Elemente")}} auf, die mithilfe von {{Glossary("Tag", "Tags")}} erstellt werden.

Sie sind nach Funktion gruppiert, damit Sie leicht finden können, wonach Sie suchen. Eine alphabetische Liste aller Elemente finden Sie in der Seitenleiste auf der Seite jedes Elements sowie auf dieser Seite.

> [!NOTE]
> Weitere Informationen über die Grundlagen von HTML-Elementen und -Attributen finden Sie unter [Anatomie eines HTML-Elements](/de/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax#anatomy_of_an_html_element).

## Hauptwurzelelement

| Element                 | Beschreibung                                                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("html")}} | Repräsentiert die Wurzel (das oberste Element) eines HTML-Dokuments und wird daher auch als _Wurzelelement_ bezeichnet. Alle anderen Elemente müssen Nachkommen dieses Elements sein. |

## Dokumentmetadaten

Metadaten enthalten Informationen über die Seite. Dazu gehören Informationen über Styles, Skripte und Daten, die Software ({{Glossary("search_engine", "Suchmaschinen")}}, {{Glossary("Browser", "Browser")}} usw.) beim Verwenden und Rendern der Seite unterstützen. Metadaten für Styles und Skripte können auf der Seite definiert oder mit einer anderen Datei verknüpft werden, die diese Informationen enthält.

| Element                  | Beschreibung                                                                                                                                                                                                                                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("base")}}  | Gibt die Basis-URL an, die für alle relativen URLs in einem Dokument verwendet werden soll. Es kann nur ein solches Element in einem Dokument geben.                                                                                                                                                                    |
| {{HTMLElement("head")}}  | Enthält maschinenlesbare Informationen (Metadaten) über das Dokument, etwa seinen [Titel](/de/docs/Web/HTML/Reference/Elements/title), [Skripte](/de/docs/Web/HTML/Reference/Elements/script) und [Stylesheets](/de/docs/Web/HTML/Reference/Elements/style).                                                            |
| {{HTMLElement("link")}}  | Gibt Beziehungen zwischen dem aktuellen Dokument und einer externen Ressource an. Dieses Element wird am häufigsten verwendet, um CSS zu verknüpfen, dient aber unter anderem auch dazu, Website-Icons zu etablieren (sowohl Icons im „Favicon“-Stil als auch Icons für den Startbildschirm und Apps auf Mobilgeräten). |
| {{HTMLElement("meta")}}  | Repräsentiert {{Glossary("Metadata", "Metadaten")}}, die nicht durch andere HTML-Metadaten-bezogene Elemente wie {{HTMLElement("base")}}, {{HTMLElement("link")}}, {{HTMLElement("script")}}, {{HTMLElement("style")}} und {{HTMLElement("title")}} dargestellt werden können.                                          |
| {{HTMLElement("style")}} | Enthält Style-Informationen für ein Dokument oder einen Teil eines Dokuments. Es enthält CSS, das auf den Inhalt des Dokuments angewendet wird, das dieses Element enthält.                                                                                                                                             |
| {{HTMLElement("title")}} | Definiert den Titel des Dokuments, der in der Titelleiste eines {{Glossary("Browser", "Browsers")}} oder im Tab einer Seite angezeigt wird. Es enthält nur Text; HTML-Tags innerhalb des Elements werden, falls vorhanden, ebenfalls als Klartext behandelt.                                                            |

## Wurzelelement für Abschnittseinteilung

| Element                 | Beschreibung                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("body")}} | Repräsentiert den Inhalt eines HTML-Dokuments. Es kann nur ein solches Element in einem Dokument geben. |

## Inhaltsabschnitte

Elemente zur Inhaltsabschnittseinteilung ermöglichen es Ihnen, den Dokumentinhalt in logische Teile zu gliedern. Verwenden Sie die Abschnittselemente, um eine grobe Gliederung für Ihren Seiteninhalt zu erstellen, einschließlich Kopf- und Fußzeilennavigation, sowie Überschriftselemente, um Inhaltsabschnitte zu kennzeichnen.

| Element                                                                                                                                                                                                                                                                                                                                                                                              | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("address")}}                                                                                                                                                                                                                                                                                                                                                                           | Zeigt an, dass das eingeschlossene HTML Kontaktinformationen für eine oder mehrere Personen oder für eine Organisation bereitstellt.                                                                                                                                                                                                                                                                                                               |
| {{HTMLElement("article")}}                                                                                                                                                                                                                                                                                                                                                                           | Repräsentiert eine eigenständige Komposition in einem Dokument, einer Seite, einer Anwendung oder einer Website, die unabhängig verteilt oder wiederverwendet werden soll (z. B. bei der Syndizierung). Beispiele sind ein Forenbeitrag, ein Zeitschriften- oder Zeitungsartikel, ein Blogeintrag, eine Produktkarte, ein von Nutzenden eingereichter Kommentar, ein interaktives Widget oder Gadget oder jedes andere unabhängige Inhaltselement. |
| {{HTMLElement("aside")}}                                                                                                                                                                                                                                                                                                                                                                             | Repräsentiert einen Teil eines Dokuments, dessen Inhalt nur indirekt mit dem Hauptinhalt des Dokuments zusammenhängt. Asides werden häufig als Seitenleisten oder Hinweisfelder dargestellt.                                                                                                                                                                                                                                                       |
| {{HTMLElement("footer")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert eine Fußzeile für das nächstgelegene übergeordnete Element für [Abschnittsinhalte](/de/docs/Web/HTML/Guides/Content_categories#sectioning_content) oder [Abschnittswurzel](/de/docs/Web/HTML/Reference/Elements/Heading_Elements). Ein `<footer>` enthält typischerweise Informationen über den Autor des Abschnitts, Copyright-Daten oder Links zu verwandten Dokumenten.                                                           |
| {{HTMLElement("header")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert einleitenden Inhalt, typischerweise eine Gruppe einleitender oder navigationsbezogener Hilfsmittel. Es kann einige Überschriftselemente, aber auch ein Logo, ein Suchformular, einen Autorennamen und weitere Elemente enthalten.                                                                                                                                                                                                    |
| [`<h1>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h2>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h3>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h4>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h5>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h6>`](/de/docs/Web/HTML/Reference/Elements/Heading_Elements) | Repräsentieren sechs Ebenen von Abschnittsüberschriften. `<h1>` ist die höchste und `<h6>` die niedrigste Abschnittsebene.                                                                                                                                                                                                                                                                                                                         |
| {{HTMLElement("hgroup")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert eine Überschrift, die mit sekundärem Inhalt gruppiert ist, etwa Unterüberschriften, einem alternativen Titel oder einem Slogan.                                                                                                                                                                                                                                                                                                      |
| {{HTMLElement("main")}}                                                                                                                                                                                                                                                                                                                                                                              | Repräsentiert den dominanten Inhalt des Body eines Dokuments. Der Hauptinhaltsbereich besteht aus Inhalten, die direkt mit dem zentralen Thema eines Dokuments oder der zentralen Funktionalität einer Anwendung zusammenhängen oder diese erweitern.                                                                                                                                                                                              |
| {{HTMLElement("nav")}}                                                                                                                                                                                                                                                                                                                                                                               | Repräsentiert einen Abschnitt einer Seite, dessen Zweck darin besteht, Navigationslinks bereitzustellen, entweder innerhalb des aktuellen Dokuments oder zu anderen Dokumenten. Häufige Beispiele für Navigationsabschnitte sind Menüs, Inhaltsverzeichnisse und Indizes.                                                                                                                                                                          |
| {{HTMLElement("section")}}                                                                                                                                                                                                                                                                                                                                                                           | Repräsentiert einen allgemeinen eigenständigen Abschnitt eines Dokuments, für den es kein spezifischeres semantisches Element gibt. Abschnitte sollten, mit sehr wenigen Ausnahmen, immer eine Überschrift haben.                                                                                                                                                                                                                                  |
| {{HTMLElement("search")}}                                                                                                                                                                                                                                                                                                                                                                            | Repräsentiert einen Teil, der eine Gruppe von Formular-Steuerelementen oder andere Inhalte enthält, die mit der Durchführung einer Suche oder Filteroperation zusammenhängen.                                                                                                                                                                                                                                                                      |

## Textinhalt

Verwenden Sie HTML-Elemente für Textinhalt, um Blöcke oder Abschnitte von Inhalt zu organisieren, die zwischen den öffnenden {{HTMLElement("body")}}- und schließenden `</body>`-Tags platziert sind. Diese Elemente sind wichtig für {{Glossary("accessibility", "Barrierefreiheit")}} und {{Glossary("SEO", "SEO")}} und kennzeichnen den Zweck oder die Struktur dieses Inhalts.

| Element                       | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("blockquote")}} | Zeigt an, dass der eingeschlossene Text ein längeres Zitat ist. Üblicherweise wird dies visuell durch Einrückung dargestellt. Eine URL für die Quelle des Zitats kann mit dem Attribut `cite` angegeben werden, während eine Textdarstellung der Quelle mit dem Element {{HTMLElement("cite")}} angegeben werden kann.                                                                                                                                                                        |
| {{HTMLElement("dd")}}         | Stellt die Beschreibung, Definition oder den Wert für den vorangehenden Begriff ({{HTMLElement("dt")}}) in einer Beschreibungsliste ({{HTMLElement("dl")}}) bereit.                                                                                                                                                                                                                                                                                                                           |
| {{HTMLElement("div")}}        | Der allgemeine Container für Flow-Inhalt. Er hat keine Auswirkung auf Inhalt oder Layout, bis er auf irgendeine Weise mit CSS gestaltet wird (z. B. indem Styling direkt darauf angewendet wird oder indem auf sein übergeordnetes Element ein Layoutmodell wie {{Glossary("Flexbox", "Flexbox")}} angewendet wird).                                                                                                                                                                          |
| {{HTMLElement("dl")}}         | Repräsentiert eine Beschreibungsliste. Das Element umschließt eine Liste von Gruppen aus Begriffen (angegeben mit dem Element {{HTMLElement("dt")}}) und Beschreibungen (bereitgestellt durch {{HTMLElement("dd")}}-Elemente). Häufige Verwendungen dieses Elements sind die Umsetzung eines Glossars oder die Anzeige von Metadaten (einer Liste von Schlüssel-Wert-Paaren).                                                                                                                 |
| {{HTMLElement("dt")}}         | Gibt einen Begriff in einer Beschreibungs- oder Definitionsliste an und muss daher innerhalb eines Elements {{HTMLElement("dl")}} verwendet werden. Ihm folgt normalerweise ein Element {{HTMLElement("dd")}}; mehrere aufeinanderfolgende `<dt>`-Elemente zeigen jedoch mehrere Begriffe an, die alle durch das unmittelbar folgende Element {{HTMLElement("dd")}} definiert werden.                                                                                                         |
| {{HTMLElement("figcaption")}} | Repräsentiert eine Bildunterschrift oder Legende, die den restlichen Inhalt des übergeordneten Elements {{HTMLElement("figure")}} beschreibt.                                                                                                                                                                                                                                                                                                                                                 |
| {{HTMLElement("figure")}}     | Repräsentiert eigenständigen Inhalt, möglicherweise mit einer optionalen Beschriftung, die mit dem Element {{HTMLElement("figcaption")}} angegeben wird. Die Abbildung, ihre Beschriftung und ihr Inhalt werden als eine einzelne Einheit referenziert.                                                                                                                                                                                                                                       |
| {{HTMLElement("hr")}}         | Repräsentiert einen thematischen Bruch zwischen Elementen auf Absatzebene: beispielsweise einen Szenenwechsel in einer Geschichte oder einen Themenwechsel innerhalb eines Abschnitts.                                                                                                                                                                                                                                                                                                        |
| {{HTMLElement("li")}}         | Repräsentiert ein Element in einer Liste. Es muss in einem übergeordneten Element enthalten sein: einer geordneten Liste ({{HTMLElement("ol")}}), einer ungeordneten Liste ({{HTMLElement("ul")}}) oder einem Menü ({{HTMLElement("menu")}}). In Menüs und ungeordneten Listen werden Listenelemente üblicherweise mit Aufzählungszeichen dargestellt. In geordneten Listen werden sie üblicherweise mit einem aufsteigenden Zähler links dargestellt, etwa einer Zahl oder einem Buchstaben. |
| {{HTMLElement("menu")}}       | Eine semantische Alternative zu {{HTMLElement("ul")}}, die jedoch von Browsern (und über den Barrierefreiheitsbaum) nicht anders als {{HTMLElement("ul")}} behandelt wird. Es repräsentiert eine ungeordnete Liste von Elementen (die durch {{HTMLElement("li")}}-Elemente dargestellt werden).                                                                                                                                                                                               |
| {{HTMLElement("ol")}}         | Repräsentiert eine geordnete Liste von Elementen — typischerweise als nummerierte Liste dargestellt.                                                                                                                                                                                                                                                                                                                                                                                          |
| {{HTMLElement("p")}}          | Repräsentiert einen Absatz. Absätze werden in visuellen Medien üblicherweise als Textblöcke dargestellt, die durch Leerzeilen und/oder Einrückung der ersten Zeile von benachbarten Blöcken getrennt sind. HTML-Absätze können jedoch jede strukturelle Gruppierung verwandter Inhalte sein, etwa Bilder oder Formularfelder.                                                                                                                                                                 |
| {{HTMLElement("pre")}}        | Repräsentiert vorformatierten Text, der genau so dargestellt werden soll, wie er in der HTML-Datei geschrieben ist. Der Text wird typischerweise mit einer nichtproportionalen oder [Monospace-](https://en.wikipedia.org/wiki/Monospaced_font)Schriftart dargestellt. Leerraum innerhalb dieses Elements wird wie geschrieben angezeigt.                                                                                                                                                     |
| {{HTMLElement("ul")}}         | Repräsentiert eine ungeordnete Liste von Elementen, typischerweise als Liste mit Aufzählungszeichen dargestellt.                                                                                                                                                                                                                                                                                                                                                                              |

## Semantik für Inline-Text

Verwenden Sie die HTML-Semantik für Inline-Text, um die Bedeutung, Struktur oder den Stil eines Wortes, einer Zeile oder eines beliebigen Textausschnitts zu definieren.

| Element                   | Beschreibung                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| {{HTMLElement("a")}}      | Erstellt zusammen mit seinem Attribut `href` einen Hyperlink zu Webseiten, Dateien, E-Mail-Adressen, Stellen innerhalb der aktuellen Seite oder allem anderen, das eine URL adressieren kann.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| {{HTMLElement("abbr")}}   | Repräsentiert eine Abkürzung oder ein Akronym.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| {{HTMLElement("b")}}      | Wird verwendet, um die Aufmerksamkeit der Lesenden auf den Inhalt des Elements zu lenken, dem ansonsten keine besondere Wichtigkeit zukommt. Früher war dies als Boldface-Element bekannt, und die meisten Browser stellen den Text weiterhin fett dar. Sie sollten `<b>` jedoch nicht zum Gestalten von Text oder zur Hervorhebung von Wichtigkeit verwenden. Wenn Sie fetten Text erstellen möchten, sollten Sie die CSS-Eigenschaft {{cssxref("font-weight")}} verwenden. Wenn Sie angeben möchten, dass ein Element von besonderer Bedeutung ist, sollten Sie das Element {{HTMLElement("strong")}} verwenden. |
| {{HTMLElement("bdi")}}    | Weist den bidirektionalen Algorithmus des Browsers an, den enthaltenen Text isoliert von seinem umgebenden Text zu behandeln. Dies ist besonders nützlich, wenn eine Website dynamisch Text einfügt und die Schreibrichtung des einzufügenden Textes nicht kennt.                                                                                                                                                                                                                                                                                                                                                  |
| {{HTMLElement("bdo")}}    | Überschreibt die aktuelle Schreibrichtung von Text, sodass der enthaltene Text in einer anderen Richtung gerendert wird.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| {{HTMLElement("br")}}     | Erzeugt einen Zeilenumbruch im Text (Wagenrücklauf). Es ist nützlich, um ein Gedicht oder eine Adresse zu schreiben, bei denen die Zeilenteilung bedeutsam ist.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| {{HTMLElement("cite")}}   | Wird verwendet, um den Titel eines kreativen Werks auszuzeichnen. Die Referenz kann entsprechend kontextangemessenen Konventionen für Zitatmetadaten in abgekürzter Form vorliegen.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("code")}}   | Zeigt seinen Inhalt in einer Weise formatiert an, die darauf hinweisen soll, dass der Text ein kurzes Fragment von Computercode ist. Standardmäßig wird der Inhaltstext mit der Standard-Monospace-Schriftart des User-Agents angezeigt.                                                                                                                                                                                                                                                                                                                                                                           |
| {{HTMLElement("data")}}   | Verknüpft einen gegebenen Inhalt mit einer maschinenlesbaren Übersetzung. Wenn der Inhalt zeit- oder datumsbezogen ist, muss das Element `<time>` verwendet werden.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| {{HTMLElement("dfn")}}    | Wird verwendet, um den im Kontext einer Definitionsphrase oder eines Definitionssatzes definierten Begriff anzugeben. Das übergeordnete Element {{HTMLElement("p")}}, die Paarung {{HTMLElement("dt")}}/{{HTMLElement("dd")}} oder der nächstgelegene Abschnittsvorfahr des Elements `<dfn>` wird als Definition des Begriffs betrachtet.                                                                                                                                                                                                                                                                          |
| {{HTMLElement("em")}}     | Kennzeichnet Text mit Betonung. Das Element `<em>` kann verschachtelt werden, wobei jede Verschachtelungsebene einen stärkeren Betonungsgrad anzeigt.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("i")}}      | Repräsentiert einen Textbereich, der aus irgendeinem Grund vom normalen Text abgesetzt ist, etwa idiomatischen Text, technische Begriffe und taxonomische Bezeichnungen. Historisch wurden diese kursiv dargestellt, was der ursprüngliche Grund für die Benennung dieses Elements als `<i>` ist.                                                                                                                                                                                                                                                                                                                  |
| {{HTMLElement("kbd")}}    | Repräsentiert einen Bereich von Inline-Text, der eine textuelle Benutzereingabe von einer Tastatur, Spracheingabe oder einem anderen Texteingabegerät bezeichnet. Konventionsgemäß rendert der User-Agent den Inhalt eines Elements `<kbd>` standardmäßig mit seiner Standard-Monospace-Schriftart, obwohl dies nicht vom HTML-Standard vorgeschrieben ist.                                                                                                                                                                                                                                                        |
| {{HTMLElement("mark")}}   | Repräsentiert Text, der aufgrund der Relevanz der markierten Passage im umschließenden Kontext zu Referenz- oder Notizzwecken markiert oder hervorgehoben ist.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| {{HTMLElement("q")}}      | Zeigt an, dass der eingeschlossene Text ein kurzes Inline-Zitat ist. Die meisten modernen Browser setzen den Text dazu in Anführungszeichen. Dieses Element ist für kurze Zitate vorgesehen, die keine Absatzumbrüche erfordern; verwenden Sie für lange Zitate das Element {{HTMLElement("blockquote")}}.                                                                                                                                                                                                                                                                                                         |
| {{HTMLElement("rp")}}     | Wird verwendet, um Ersatzklammern für Browser bereitzustellen, die die Anzeige von Ruby-Anmerkungen mit dem Element {{HTMLElement("ruby")}} nicht unterstützen. Ein Element `<rp>` sollte jeweils die öffnende und schließende Klammer umschließen, die das Element {{HTMLElement("rt")}} mit dem Text der Anmerkung umgeben.                                                                                                                                                                                                                                                                                      |
| {{HTMLElement("rt")}}     | Gibt die Ruby-Textkomponente einer Ruby-Anmerkung an, die verwendet wird, um Informationen zur Aussprache, Übersetzung oder Transliteration für ostasiatische Typografie bereitzustellen. Das Element `<rt>` muss immer innerhalb eines Elements {{HTMLElement("ruby")}} enthalten sein.                                                                                                                                                                                                                                                                                                                           |
| {{HTMLElement("ruby")}}   | Repräsentiert kleine Anmerkungen, die über, unter oder neben Basistext gerendert werden und üblicherweise zur Anzeige der Aussprache ostasiatischer Zeichen verwendet werden. Es kann auch für Anmerkungen zu anderen Textarten verwendet werden, aber diese Verwendung ist weniger verbreitet.                                                                                                                                                                                                                                                                                                                    |
| {{HTMLElement("s")}}      | Rendert Text mit Durchstreichung oder einer Linie durch den Text. Verwenden Sie das Element `<s>`, um Dinge darzustellen, die nicht länger relevant oder nicht mehr korrekt sind. `<s>` ist jedoch nicht geeignet, um Dokumentbearbeitungen anzuzeigen; verwenden Sie dafür nach Bedarf die Elemente {{HTMLElement("del")}} und {{HTMLElement("ins")}}.                                                                                                                                                                                                                                                            |
| {{HTMLElement("samp")}}   | Wird verwendet, um Inline-Text einzuschließen, der eine Beispielausgabe (oder zitierte Ausgabe) eines Computerprogramms darstellt. Sein Inhalt wird typischerweise mit der Standard-Monospace-Schriftart des Browsers gerendert (etwa [Courier](<https://en.wikipedia.org/wiki/Courier_(typeface)>) oder Lucida Console).                                                                                                                                                                                                                                                                                          |
| {{HTMLElement("small")}}  | Repräsentiert Nebenbemerkungen und Kleingedrucktes, etwa Copyright- und Rechtstexte, unabhängig von ihrer formatierten Darstellung. Standardmäßig wird Text darin eine Schriftgröße kleiner gerendert, etwa von `small` zu `x-small`.                                                                                                                                                                                                                                                                                                                                                                              |
| {{HTMLElement("span")}}   | Ein allgemeiner Inline-Container für Phraseninhalt, der von sich aus nichts repräsentiert. Er kann verwendet werden, um Elemente zu Stylingzwecken zu gruppieren (unter Verwendung der Attribute `class` oder `id`) oder weil sie Attributwerte wie `lang` gemeinsam haben. Er sollte nur verwendet werden, wenn kein anderes semantisches Element geeignet ist. `<span>` ist einem div-Element sehr ähnlich, aber div ist ein {{Glossary("Block-level_content", "Element auf Blockebene")}}, während ein `<span>` ein {{Glossary("Inline-level_content", "Element auf Inline-Ebene")}} ist.                       |
| {{HTMLElement("strong")}} | Zeigt an, dass sein Inhalt von starker Bedeutung, Ernsthaftigkeit oder Dringlichkeit ist. Browser rendern den Inhalt typischerweise fett.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| {{HTMLElement("sub")}}    | Gibt Inline-Text an, der aus rein typografischen Gründen als tiefgestellter Text angezeigt werden soll. Tiefgestellter Text wird typischerweise mit einer tiefergelegten Grundlinie und kleinerem Text gerendert.                                                                                                                                                                                                                                                                                                                                                                                                  |
| {{HTMLElement("sup")}}    | Gibt Inline-Text an, der aus rein typografischen Gründen als hochgestellter Text angezeigt werden soll. Hochgestellter Text wird typischerweise mit einer angehobenen Grundlinie und kleinerem Text gerendert.                                                                                                                                                                                                                                                                                                                                                                                                     |
| {{HTMLElement("time")}}   | Repräsentiert einen bestimmten Zeitraum. Es kann das Attribut `datetime` enthalten, um Daten in ein maschinenlesbares Format zu übersetzen und dadurch bessere Suchmaschinenergebnisse oder benutzerdefinierte Funktionen wie Erinnerungen zu ermöglichen.                                                                                                                                                                                                                                                                                                                                                         |
| {{HTMLElement("u")}}      | Repräsentiert einen Bereich von Inline-Text, der so gerendert werden soll, dass er eine nichttextuelle Anmerkung anzeigt. Standardmäßig wird dies als einfache durchgehende Unterstreichung gerendert, kann jedoch mit CSS geändert werden.                                                                                                                                                                                                                                                                                                                                                                        |
| {{HTMLElement("var")}}    | Repräsentiert den Namen einer Variablen in einem mathematischen Ausdruck oder einem Programmierkontext. Er wird typischerweise in einer kursiven Variante der aktuellen Schriftart dargestellt, obwohl dieses Verhalten vom Browser abhängt.                                                                                                                                                                                                                                                                                                                                                                       |
| {{HTMLElement("wbr")}}    | Repräsentiert eine mögliche Wortumbruchstelle — eine Position innerhalb von Text, an der der Browser optional eine Zeile umbrechen kann, obwohl seine Zeilenumbruchregeln dort ansonsten keinen Umbruch erzeugen würden.                                                                                                                                                                                                                                                                                                                                                                                           |

## Bilder und Multimedia

HTML unterstützt verschiedene Multimediaressourcen wie Bilder, Audio und Video.

| Element                  | Beschreibung                                                                                                                                                                                                                                                                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("area")}}  | Definiert einen Bereich innerhalb einer Image-Map mit vordefinierten anklickbaren Bereichen. Eine _Image-Map_ ermöglicht die Zuordnung geometrischer Bereiche auf einem Bild zu einem {{Glossary("Hyperlink", "Hyperlink")}}.                                                                                                                            |
| {{HTMLElement("audio")}} | Wird verwendet, um Audioinhalte in Dokumente einzubetten. Es kann eine oder mehrere Audioquellen enthalten, die mit dem Attribut `src` oder dem Source-Element dargestellt werden: Der Browser wählt die am besten geeignete aus. Es kann auch das Ziel für gestreamte Medien unter Verwendung eines [`MediaStream`](/de/docs/Web/API/MediaStream) sein. |
| {{HTMLElement("img")}}   | Bettet ein Bild in das Dokument ein.                                                                                                                                                                                                                                                                                                                     |
| {{HTMLElement("map")}}   | Wird zusammen mit {{HTMLElement("area")}}-Elementen verwendet, um eine Image-Map (einen anklickbaren Linkbereich) zu definieren.                                                                                                                                                                                                                         |
| {{HTMLElement("track")}} | Wird als Kindelement der Medienelemente Audio und Video verwendet. Damit können Sie zeitgesteuerte Textspuren (oder zeitbasierte Daten) angeben, beispielsweise um Untertitel automatisch zu verarbeiten. Web Components ist eine HTML-bezogene Technologie, die es im Wesentlichen ermöglicht, benutzerdefinierte Elemente zu erstellen und zu verwenden, als wären sie reguläres HTML. Zusätzlich können Sie benutzerdefinierte Versionen von Standard-HTML-Elementen erstellen.

| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("slot")}}     | Als Teil der Technologie-Suite [Web Components](/de/docs/Web/API/Web_components) ist dieses Element ein Platzhalter innerhalb einer Webkomponente, den Sie mit Ihrem eigenen Markup füllen können. Dadurch können Sie separate DOM-Bäume erstellen und sie gemeinsam darstellen. |
