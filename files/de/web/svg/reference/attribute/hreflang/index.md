Das Attribut **`hreflang`** gibt die menschliche Sprache der Ressource an, auf die ein SVG-Element {{SVGElement("a")}} verweist. Sie können dieses Attribut mit dem folgenden SVG-Element verwenden:

- {{SVGElement("a")}}

## Beispiel

```html
<svg viewBox="0 0 150 20" xmlns="http://www.w3.org/2000/svg">
  <a href="https://example.com" hreflang="en">
    <text x="5" y="15">Website</text>
  </a>
</svg>
```
