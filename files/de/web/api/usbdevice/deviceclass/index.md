Die schreibgeschützte **`deviceClass`**-Eigenschaft des [`USBDevice`](/de/docs/Web/API/USBDevice)-Interfaces ist eine von drei Eigenschaften, die USB-Geräte zur Ladezwecken eines mit diesem Gerät funktionierenden USB-Treibers identifizieren. Die anderen beiden Eigenschaften sind `USBDevice.deviceSubclass` und `USBDevice.deviceProtocol`.

## Wert

Eine Zahl.
