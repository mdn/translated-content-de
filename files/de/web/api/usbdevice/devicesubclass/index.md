Die **`deviceSubclass`** Nur-Lese-Eigenschaft des
[`USBDevice`](/de/docs/Web/API/USBDevice)-Interfaces ist eine von drei Eigenschaften, die USB-Geräte identifizieren, um einen USB-Treiber zu laden, der mit diesem Gerät kompatibel ist. Die anderen beiden Eigenschaften sind USBDevice.deviceClass und USBDevice.deviceProtocol.

## Wert

Eine Zahl.
