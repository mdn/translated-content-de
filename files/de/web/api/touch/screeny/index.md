Die schreibgeschützte Eigenschaft **`screenY`** der Schnittstelle [`Touch`](/de/docs/Web/API/Touch) gibt die Y-Koordinate des Berührungspunkts relativ zum Bildschirm zurück, ohne einen Scroll-Offset zu berücksichtigen.

## Wert

Eine Zahl.

## Beispiele

Das [Beispiel zu Touch.screenX](/de/docs/Web/API/Touch/screenX#examples) zeigt auch die Verwendung dieser Eigenschaft.
