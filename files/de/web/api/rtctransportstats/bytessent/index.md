Die **`bytesSent`**-Eigenschaft des [`RTCTransportStats`](/de/docs/Web/API/RTCTransportStats)-Wörterbuchs zeigt die Gesamtanzahl der Nutzdatenbytes an, die über diesen Transport gesendet wurden.

Es werden nur die Datenbytes gezählt; Overhead wie Padding, Header usw. sind in dieser Zählung nicht enthalten.

## Wert

Eine nicht-negative ganze Zahl, die die Anzahl der gesendeten Nutzdatenbytes angibt.
