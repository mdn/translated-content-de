Die **`packetsSent`**-Eigenschaft des [`RTCTransportStats`](/de/docs/Web/API/RTCTransportStats)-Wörterbuchs gibt die Gesamtzahl der über diesen Transport gesendeten Pakete an.

## Wert

Eine positive ganze Zahl, die die Anzahl der über den Transport gesendeten Pakete angibt.
