{{APIRef("Performance API")}}

Die veraltete **`PerformanceNavigation.redirectCount`**-Eigenschaft ist eine schreibgeschützte Eigenschaft, die ein `unsigned short` zurückgibt. Dieser Wert repräsentiert die Anzahl der REDIRECTs, die vor dem Erreichen der Seite durchgeführt wurden.

> [!WARNING]
> Diese Schnittstelle dieser Eigenschaft ist im [Navigation Timing Level 2 Spezifikation](https://w3c.github.io/navigation-timing/#obsolete) veraltet.
> Bitte verwenden Sie stattdessen die [`PerformanceNavigationTiming`](/de/docs/Web/API/PerformanceNavigationTiming)-Schnittstelle.

## Wert

Ein `unsigned short`.
