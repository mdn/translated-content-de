Die **`ax`**-Eigenschaft der [`CSSSkewX`](/de/docs/Web/API/CSSSkewX)-Schnittstelle erhält und setzt den Winkel, der verwendet wird, um das Element entlang der x-Achse (oder Abszisse) zu verzerren.

## Wert

Ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue).

## Beispiele

Noch ausstehend
