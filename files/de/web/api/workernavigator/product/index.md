{{APIRef("HTML DOM")}}{{AvailableInWorkers("worker")}}

Die schreibgeschützte Eigenschaft **`product`** der Schnittstelle [`WorkerNavigator`](/de/docs/Web/API/WorkerNavigator) hat in jedem Browser immer den Wert `"Gecko"`. Diese Eigenschaft wird nur aus Kompatibilitätsgründen beibehalten.

> [!NOTE]
> Verlassen Sie sich nicht darauf, dass diese Eigenschaft einen tatsächlichen Produktnamen zurückgibt. Alle Browser geben für diese Eigenschaft `"Gecko"` zurück.

## Wert

Die Zeichenfolge `"Gecko"`.
