{{APIRef("HTML DOM")}}

Die Eigenschaft **`selectionStart`** der Schnittstelle [`HTMLTextAreaElement`](/de/docs/Web/API/HTMLTextAreaElement) gibt die Startposition der aktuellen Textauswahl in einem {{HTMLElement("textarea")}}-Element an.

Allgemeine Informationen zu dieser Eigenschaft finden Sie unter [`HTMLInputElement.selectionStart`](/de/docs/Web/API/HTMLInputElement/selectionStart).

## Wert

Eine nicht negative Zahl, die den nullbasierten Index des ersten ausgewählten Zeichens angibt. Wenn kein Text ausgewählt ist, gibt sie die Position der Einfügemarke an.
