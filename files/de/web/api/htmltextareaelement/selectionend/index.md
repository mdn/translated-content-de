{{APIRef("HTML DOM")}}

Die Eigenschaft **`selectionEnd`** der Schnittstelle [`HTMLTextAreaElement`](/de/docs/Web/API/HTMLTextAreaElement) gibt die Endposition der aktuellen Textauswahl in einem {{HTMLElement("textarea")}}-Element an.

Allgemeine Informationen zu dieser Eigenschaft finden Sie unter [`HTMLInputElement.selectionEnd`](/de/docs/Web/API/HTMLInputElement/selectionEnd).

## Wert

Eine nicht negative Zahl, die den nullbasierten Index unmittelbar nach dem letzten ausgewählten Zeichen angibt, oder die Position des Textcursors, wenn kein Text ausgewählt ist.
