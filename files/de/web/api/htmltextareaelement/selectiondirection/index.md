{{APIRef("HTML DOM")}}

Die Eigenschaft **`selectionDirection`** der Schnittstelle [`HTMLTextAreaElement`](/de/docs/Web/API/HTMLTextAreaElement) ist eine Zeichenfolge, die angibt, in welche Richtung der Benutzer den Text auswählt.

Allgemeine Informationen zu dieser Eigenschaft finden Sie unter [`HTMLInputElement.selectionDirection`](/de/docs/Web/API/HTMLInputElement/selectionDirection).

## Wert

Eine Zeichenfolge: `"forward"`, `"backward"` oder `"none"`.
