{{APIRef("CSS Typed Object Model API")}} {{AvailableInWorkers}}

Das **`CSSPerspective`**-Interface der [CSS Typed Object Model API](/de/docs/Web/API/CSS_Object_Model) repräsentiert den Wert der {{cssxref("transform-function/perspective", "perspective()")}}-Funktion der einzelnen {{CSSXRef('transform')}}-Eigenschaft in CSS. Es erbt Eigenschaften und Methoden von seinem übergeordneten [`CSSTransformValue`](/de/docs/Web/API/CSSTransformValue).

{{InheritanceDiagram}}

## Konstruktor

- [`CSSPerspective()`](/de/docs/Web/API/CSSPerspective/CSSPerspective)
  - : Erstellt ein neues `CSSPerspective`-Objekt.

## Instanzeigenschaften

- [`length`](/de/docs/Web/API/CSSPerspective/length)
  - : Gibt die Entfernung von z=0 zurück oder setzt diese.
