Dieses Boolean-Attribut steuert den Bildschirm des Geräts. Wenn es auf `false` gesetzt wird, wird der Bildschirm ausgeschaltet.

## Wert

Ein Boolean.

## Spezifikationen

Nicht Teil einer Spezifikation.
