Die **`compact`**-Eigenschaft der Schnittstelle [`HTMLOListElement`](/de/docs/Web/API/HTMLOListElement) gibt an, dass der Abstand zwischen Listenelementen reduziert werden sollte. Die genaue Handhabung des `compact`-Attributs ist browser-spezifisch. Anstatt diese Eigenschaft zu verwenden, sollten Sie stattdessen CSS {{cssxref("line-height")}} in Betracht ziehen.

Sie spiegelt das [`compact`](/de/docs/Web/HTML/Reference/Elements/ol#compact)-Attribut des {{HTMLElement("ol")}}-Elements wider.

## Wert

Ein boolescher Wert.
