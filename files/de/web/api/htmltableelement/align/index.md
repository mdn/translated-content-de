{{APIRef("HTML DOM")}}

Die **`HTMLTableElement.align`**-Eigenschaft repräsentiert die Ausrichtung der Tabelle.

## Wert

Einer der folgenden Zeichenfolgenwerte:

- `left`
- `center`
- `right`

## Beispiele

```js
// Set the alignment of a table
const t = document.getElementById("TableA");
t.align = "center";
```
