{{APIRef("CSS Typed Object Model API")}}

Die **`x`**-Eigenschaft der [`CSSRotate`](/de/docs/Web/API/CSSRotate)-Schnittstelle liest oder setzt die Abszisse oder x-Achse des Translationsvektors.

## Wert

Ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue). Kann auf eine Zahl gesetzt werden, die in einen [`CSSUnitValue`](/de/docs/Web/API/CSSUnitValue) des `unit: "number"` eingebettet ist.
