Die **`variable`**-Eigenschaft der
[`CSSVariableReferenceValue`](/de/docs/Web/API/CSSVariableReferenceValue)-Schnittstelle gibt den [Namen der benutzerdefinierten Eigenschaft](/de/docs/Web/CSS/Reference/Properties/--*) der
[`CSSVariableReferenceValue`](/de/docs/Web/API/CSSVariableReferenceValue) zurück.

## Wert

Ein Zeichenfolgenwert, der mit `--` beginnt (also ein [Name der benutzerdefinierten Eigenschaft](/de/docs/Web/CSS/Reference/Properties/--*)).
