{{APIRef("CSS Font Loading API")}}{{AvailableInWorkers}}

Die **`entries()`**-Methode der [`FontFaceSet`](/de/docs/Web/API/FontFaceSet)-Schnittstelle gibt ein neues {{jsxref("Iterator")}}-Objekt zurück, das für jedes Element im `FontFaceSet` ein Array der Form `[value,value]` enthält.

## Syntax

```js-nolint
entries()
```

### Parameter

Keine.

### Rückgabewert

Ein neues Iterator-Objekt, das für jedes Element im `FontFaceSet` ein Array der Form `[value, value]` in der Reihenfolge des Einfügens enthält.
