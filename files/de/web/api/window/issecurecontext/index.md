Die **`isSecureContext`** schreibgeschützte Eigenschaft der [`Window`](/de/docs/Web/API/Window)-Schnittstelle gibt einen Boolean-Wert zurück, der angibt, ob der aktuelle [Kontext sicher ist](/de/docs/Web/Security/Defenses/Secure_Contexts) (`true`) oder nicht (`false`).

## Wert

Ein Boolean.
