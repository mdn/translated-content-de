{{APIRef("HTML DOM")}}

Die **`status`**-Eigenschaft der [`Window`](/de/docs/Web/API/Window)-Schnittstelle war ursprünglich dazu gedacht, den Text in der Statusleiste am unteren Rand des Browserfensters festzulegen. Allerdings erfordert der HTML-Standard nun, dass das Setzen von `window.status` keinen Effekt auf den in der Statusleiste angezeigten Text hat.

## Wert

Ein String.
