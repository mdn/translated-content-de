{{APIRef("HTML DOM")}}

**`window.document`** gibt eine Referenz auf das im Fenster enthaltene [document](/de/docs/Web/API/Document) zurück.

## Wert

Ein [document](/de/docs/Web/API/Document)-Objekt.

## Beispiele

```js
console.log(window.document.title);
```
