{{APIRef("UI Events")}}

Die schreibgeschützte **`data`**-Eigenschaft des [`TextEvent`](/de/docs/Web/API/TextEvent)-Interfaces gibt das zuletzt zum Eingabeelement hinzugefügte Zeichen zurück.

## Wert

Ein String, der die Event-Daten repräsentiert.
Für `textInput`-Events ist dies das Zeichen, das zuletzt eingegeben wurde.
