{{APIRef("DOM")}}

Die schreibgeschützte Eigenschaft **`quota`** der Schnittstelle [`QuotaExceededError`](/de/docs/Web/API/QuotaExceededError) gibt das vom System festgelegte Speicherkontingent (in Bytes) zurück, das der Vorgang zu überschreiten versuchte. Wenn diese Information nicht verfügbar ist, gibt sie `undefined` zurück.

## Wert

Eine Zahl, die das Speicherkontingent in Bytes angibt, oder `undefined`.
