Das **`CSSMathInvert`**-Interface der [CSS Typed Object Model API](/de/docs/Web/API/CSS_Object_Model) repräsentiert ein CSS-{{CSSXref('calc','calc()')}}, das als `calc(1 / <value>)` verwendet wird.

{{InheritanceDiagram}}

## Konstruktor

- [`CSSMathInvert()`](/de/docs/Web/API/CSSMathInvert/CSSMathInvert)
  - : Erstellt ein neues `CSSMathInvert`-Objekt.

## Instanz-Eigenschaften

_Erbt auch Eigenschaften von seinem Eltern-Interface, [`CSSMathValue`](/de/docs/Web/API/CSSMathValue)._

- [`CSSMathInvert.value`](/de/docs/Web/API/CSSMathInvert/value) {{ReadOnlyInline}}
  - : Gibt ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue)-Objekt zurück.
