{{APIRef("SVG")}}

Die **`port`**-Eigenschaft der [`SVGAElement`](/de/docs/Web/API/SVGAElement)-Schnittstelle gibt einen String zurück, der die Portkomponente, falls vorhanden, der referenzierten URL darstellt.

Diese Eigenschaft kann gesetzt werden, um den Port der URL zu ändern.

## Wert

Ein String.
