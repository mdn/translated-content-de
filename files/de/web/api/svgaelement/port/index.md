Die **`port`**-Eigenschaft des [`SVGAElement`](/de/docs/Web/API/SVGAElement)-Interfaces gibt einen String zurück, der die Port-Komponente der referenzierten URL darstellt, falls vorhanden.

Diese Eigenschaft kann gesetzt werden, um den Port der URL zu ändern.

## Wert

Ein String.
