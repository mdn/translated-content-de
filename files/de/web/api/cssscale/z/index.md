Die **`z`**-Eigenschaft der [`CSSScale`](/de/docs/Web/API/CSSScale)-Schnittstelle repräsentiert die z-Komponente des Verschiebungsvektors.
Ein positiver Wert bewegt das Element zum Betrachter hin, und ein negativer Wert weiter weg.

Wenn dieser Wert vorhanden ist, handelt es sich um eine 3D-Transformation und die `is2D`-Eigenschaft wird auf false gesetzt.

## Wert

Ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue).
Kann auf eine Zahl gesetzt werden, die in einem [`CSSUnitValue`](/de/docs/Web/API/CSSUnitValue) mit `unit: "number"` eingekapselt ist.
