Die **`z`**-Eigenschaft des [`CSSScale`](/de/docs/Web/API/CSSScale)-Interfaces repräsentiert die z-Komponente des Translationsvektors. Ein positiver Wert bewegt das Element auf den Betrachter zu, ein negativer Wert weiter weg.

Wenn dieser Wert vorhanden ist, handelt es sich um eine 3D-Transformation, und die Eigenschaft `is2D` wird auf false gesetzt.

## Wert

Ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue).
Kann auf eine Zahl gesetzt werden, die in ein [`CSSUnitValue`](/de/docs/Web/API/CSSUnitValue) mit `unit: "number"` gewickelt ist.
