{{APIRef("CSS Typed Object Model API")}}

Das **`CSSScale`**-Interface der [CSS Typed Object Model API](/de/docs/Web/API/CSS_Object_Model) repräsentiert die {{cssxref("transform-function/scale", "scale()")}}- und {{cssxref("transform-function/scale3d", "scale3d()")}}-Werte der einzelnen {{CSSXRef('transform')}}-Eigenschaft in CSS.
Es erbt Eigenschaften und Methoden von seinem Elternobjekt [`CSSTransformValue`](/de/docs/Web/API/CSSTransformValue).

{{InheritanceDiagram}}

## Konstruktor

- [`CSSScale()`](/de/docs/Web/API/CSSScale/CSSScale)
  - : Erstellt ein neues `CSSScale`-Objekt.

## Instanz-Eigenschaften

- [`x`](/de/docs/Web/API/CSSScale/x)
  - : Gibt den Wert der x-Achse zurück oder legt diesen fest.
- [`y`](/de/docs/Web/API/CSSScale/y)
  - : Gibt den Wert der y-Achse zurück oder legt diesen fest.
- [`z`](/de/docs/Web/API/CSSScale/z)
  - : Gibt den Wert der z-Achse zurück oder legt diesen fest.
