{{APIRef("HTML DOM")}}

Die schreibgeschützte Eigenschaft **`product`** der Schnittstelle [`Navigator`](/de/docs/Web/API/Navigator) gibt in jedem Browser immer `"Gecko"` zurück. Diese Eigenschaft wird nur aus Kompatibilitätsgründen beibehalten.

> [!NOTE]
> Verlassen Sie sich nicht darauf, dass diese Eigenschaft einen tatsächlichen Produktnamen zurückgibt. Alle Browser geben für diese Eigenschaft `"Gecko"` zurück.

## Wert

Die Zeichenfolge `"Gecko"`.
