{{APIRef("CSS Typed Object Model API")}}

Der **`CSSSkew()`** Konstruktor erzeugt ein neues [`CSSSkew`](/de/docs/Web/API/CSSSkew) Objekt, das den {{cssxref("transform-function/skew", "skew()")}}-Wert der einzelnen {{CSSXRef('transform')}}-Eigenschaft in CSS darstellt.

## Syntax

```js-nolint
new CSSSkew(ax, ay)
```

### Parameter

- [`ax`](/de/docs/Web/API/CSSSkew/ax)
  - : Ein Wert für den Winkel `ax` (x-Achse) des zu konstruierenden [`CSSSkew`](/de/docs/Web/API/CSSSkew) Objekts.
    Dieser muss ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue) sein.
- [`ay`](/de/docs/Web/API/CSSSkew/ay)
  - : Ein Wert für den Winkel `ay` (y-Achse) des zu konstruierenden [`CSSSkew`](/de/docs/Web/API/CSSSkew) Objekts.
    Dieser muss ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue) sein.
