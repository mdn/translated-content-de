Die schreibgeschützte **`is2D`** Eigenschaft des [`CSSTransformComponent`](/de/docs/Web/API/CSSTransformComponent)-Interfaces gibt an, ob die Transformation 2D oder 3D ist.

## Wert

Ein boolescher Wert. `true` zeigt an, dass die Transformation eine 2D-Transformation ist, `false` wenn es sich um eine 3D-Transformation handelt.
