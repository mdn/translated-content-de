Die **`is2D`**-Eigenschaft der [`CSSTransformComponent`](/de/docs/Web/API/CSSTransformComponent)-Schnittstelle gibt an, ob die Transformation in 2D oder 3D ist.

## Wert

Ein boolescher Wert. True, wenn die Transformation eine 2D-Transformation ist, false, wenn sie eine 3D-Transformation ist.
