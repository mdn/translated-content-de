{{APIRef("CSSOM")}}

Die schreibgeschützte Eigenschaft **`title`** der Schnittstelle [`StyleSheet`](/de/docs/Web/API/StyleSheet) gibt den beschreibenden Titel des aktuellen Stylesheets zurück.

Der Titel wird häufig in der [`ownerNode`](/de/docs/Web/API/StyleSheet/ownerNode) angegeben.
