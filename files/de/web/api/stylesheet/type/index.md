Die schreibgeschützte Eigenschaft **`type`** der Schnittstelle [`StyleSheet`](/de/docs/Web/API/StyleSheet) gibt die Stylesheet-Sprache des jeweiligen Stylesheets an.

## Wert

Eine Zeichenfolge.

## Beispiele

```js
myStyleSheet.type = "text/css";
```
