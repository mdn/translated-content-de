{{APIRef("HTMLMediaElement")}}

Das `ratechange`-Ereignis wird ausgelöst, wenn sich die Wiedergabegeschwindigkeit geändert hat.

Dieses Ereignis kann nicht abgebrochen werden und wird nicht weitergereicht.

## Syntax

Verwenden Sie den Ereignisnamen in [`addEventListener()`](/de/docs/Web/API/EventTarget/addEventListener):

```js-nolint
addEventListener("ratechange", (event) => { })
```

Alternativ können Sie ihn der [Event-Handler-Eigenschaft](/de/docs/Web/API/Document_Object_Model/Events#using_onevent_properties) der Schnittstelle zuweisen:

```js-nolint
onratechange = (event) => { }
```

## Ereignistyp

Ein generisches [`Event`](/de/docs/Web/API/Event).

## Beispiele

Diese Beispiele fügen einen Event-Listener für das `ratechange`-Ereignis des HTMLMediaElement hinzu und geben eine Nachricht aus, wenn der Event-Handler auf das ausgelöste Ereignis reagiert hat.

Mit `addEventListener()`:

```js
const video = document.querySelector("video");

video.addEventListener("ratechange", (event) => {
  console.log("The playback rate changed.");
});
```

Mit der Event-Handler-Eigenschaft `onratechange` (beachten Sie jedoch, dass dadurch gegebenenfalls andere mit `onratechange` hinzugefügte Event-Listener ersetzt werden):

```js
const video = document.querySelector("video");

video.onratechange = (event) => {
  console.log("The playback rate changed.");
};
```
