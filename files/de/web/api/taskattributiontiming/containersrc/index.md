Die schreibgeschützte Eigenschaft **`containerSrc`** der Schnittstelle [`TaskAttributionTiming`](/de/docs/Web/API/TaskAttributionTiming) gibt das `src`-Attribut des Containers zurück. Ein Container ist ein iframe, embed, object usw., dem insgesamt eine lang andauernde Aufgabe zugeschrieben wird.

## Wert

Ein String mit dem `src`-Attribut des Containers (z. B. [`<iframe src="url.html">`](/de/docs/Web/HTML/Reference/Elements/iframe#src)).
