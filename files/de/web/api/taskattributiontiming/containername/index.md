Die schreibgeschützte Eigenschaft **`containerName`** der Schnittstelle [`TaskAttributionTiming`](/de/docs/Web/API/TaskAttributionTiming) gibt das Attribut `name` des Containers zurück. Ein Container ist ein iframe, embed oder object usw., dem eine lang andauernde Aufgabe insgesamt zugeschrieben wird.

## Wert

Eine Zeichenfolge mit dem HTML-Inhaltsattribut `name` des Containers (z. B. [`<iframe name="myIframe">`](/de/docs/Web/HTML/Reference/Elements/iframe#name) oder [`<object name="myObject">`](/de/docs/Web/HTML/Reference/Elements/object#name)).
