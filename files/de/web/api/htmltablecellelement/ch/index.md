{{APIRef("HTML DOM")}}

Die **`ch`**-Eigenschaft des [`HTMLTableCellElement`](/de/docs/Web/API/HTMLTableCellElement)-Interfaces bewirkt nichts. Sie spiegelt das `char` Attribut des Zellen-Elements wider.

> [!NOTE]
> Diese Eigenschaft wurde ursprünglich entwickelt, um die Möglichkeit zu bieten, den Inhalt von Tabellenzellen an einem bestimmten Zeichen (typischerweise dem Dezimalpunkt) auszurichten, wurde jedoch nie von Browsern implementiert.
>
> Um eine solche Ausrichtung zu erreichen, sollten Sie auf die Unterstützung eines Zeichenfolgenwerts mit der {{cssxref("text-align")}} CSS-Eigenschaft achten.

## Wert

Ein einzelnes Zeichen.
