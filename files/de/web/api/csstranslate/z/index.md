Die **`z`**-Eigenschaft der [`CSSTranslate`](/de/docs/Web/API/CSSTranslate)-Schnittstelle repräsentiert die z-Komponente des Übersetzungvektors. Ein positiver Wert bewegt das Element in Richtung des Betrachters, ein negativer Wert weiter weg.

Wenn dieser Wert vorhanden ist, handelt es sich um eine 3D-Transformation, und die `is2D`-Eigenschaft wird auf false gesetzt.

## Wert

Ein {{cssxref('length')}}.
