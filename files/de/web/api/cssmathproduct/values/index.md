Die schreibgeschützte **`CSSMathProduct.values`**-Eigenschaft des [`CSSMathProduct`](/de/docs/Web/API/CSSMathProduct)-Interfaces gibt ein [`CSSNumericArray`](/de/docs/Web/API/CSSNumericArray)-Objekt zurück, das ein oder mehrere [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue)-Objekte enthält.

## Wert

Ein [`CSSNumericArray`](/de/docs/Web/API/CSSNumericArray).
