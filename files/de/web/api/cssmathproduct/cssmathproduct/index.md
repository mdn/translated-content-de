Der **`CSSMathProduct()`** Konstruktor erstellt ein [`CSSMathProduct`](/de/docs/Web/API/CSSMathProduct) Objekt, das die übergebenen Argumente multipliziert.

## Syntax

```js-nolint
new CSSMathProduct(args)
```

### Parameter

- `args`
  - : Eine Liste von Werten für das [`CSSMathProduct`](/de/docs/Web/API/CSSMathProduct) Objekt, die entweder ein Doppelinteger oder ein [`CSSNumericValue`](/de/docs/Web/API/CSSNumericValue) sein können.
