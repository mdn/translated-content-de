{{APIRef("HTML DOM")}}

Die **`chOff`**-Eigenschaft der [`HTMLTableRowElement`](/de/docs/Web/API/HTMLTableRowElement)-Schnittstelle hat keine Funktion. Sie spiegelt das `charoff`-Attribut des {{HTMLElement("tr")}}-Elements wider.

> [!NOTE]
> Diese Eigenschaft wurde entworfen, um an der Fähigkeit teilzunehmen, Tabellenzelleninhalt an einem bestimmten Zeichen (typischerweise dem Dezimalpunkt) auszurichten, wurde jedoch nie von Browsern implementiert.
>
> Um eine solche Ausrichtung zu erreichen, achten Sie auf die Unterstützung eines Zeichenfolgenwerts mit der {{cssxref("text-align")}} CSS-Eigenschaft.

## Wert

Eine ganze Zahl.
