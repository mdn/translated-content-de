{{APIRef("HTML DOM")}}

Die **`ch`**-Eigenschaft des [`HTMLTableRowElement`](/de/docs/Web/API/HTMLTableRowElement)-Interfaces bewirkt nichts. Sie spiegelt das `char`-Attribut des {{HTMLElement("tr")}}-Elements wider.

> [!NOTE]
> Diese Eigenschaft wurde entworfen, um die Möglichkeit zu bieten, Tabellenzelleninhalte an einem spezifischen Zeichen auszurichten (typischerweise der Dezimalpunkt), aber sie wurde nie von Browsern implementiert.
>
> Um eine solche Ausrichtung zu erreichen, sollten Sie auf die Unterstützung eines Zeichenfolgenwerts mit der {{cssxref("text-align")}}-CSS-Eigenschaft achten.

## Wert

Ein einzelnes Zeichen.
