Die schreibgeschützte **`shippingType`**-Eigenschaft der [`PaymentRequest`](/de/docs/Web/API/PaymentRequest)-Schnittstelle gibt einen der Werte `"shipping"`, `"delivery"`, `"pickup"` oder `null` zurück, falls keiner durch den Konstruktor bereitgestellt wurde.

## Wert

Einer der Werte `"shipping"`, `"delivery"`, `"pickup"` oder `null`.
