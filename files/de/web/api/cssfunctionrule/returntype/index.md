{{ APIRef("CSSOM") }}

Die **`returnType`**-Eigenschaft der [`CSSFunctionRule`](/de/docs/Web/API/CSSFunctionRule)-Schnittstelle gibt einen String zurück, der den Rückgabetyp der benutzerdefinierten Funktion angibt.

## Wert

Ein String.

Wenn in der zugehörigen {{cssxref("@function")}}-At-Regel kein Rückgabetyp angegeben ist, gibt `returnType` `*` zurück.

## Beispiele

Ein Beispiel finden Sie auf der Referenzseite zu [`CSSFunctionRule`](/de/docs/Web/API/CSSFunctionRule).
