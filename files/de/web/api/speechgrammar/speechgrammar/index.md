Der **`SpeechGrammar()`** Konstruktor der
[`SpeechGrammar`](/de/docs/Web/API/SpeechGrammar) Schnittstelle erstellt eine neue Instanz eines `SpeechGrammar` Objekts.

## Syntax

```js-nolint
new SpeechGrammar()
```

Keine.
