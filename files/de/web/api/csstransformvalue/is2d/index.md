Die schreibgeschützte **`is2D`**-Eigenschaft der [`CSSTransformValue`](/de/docs/Web/API/CSSTransformValue)-Schnittstelle gibt an, ob die Transformation 2D oder 3D ist.

Im Fall von `CSSTransformValue` gibt diese Eigenschaft wahr zurück, es sei denn, eine der einzelnen Funktionen gibt für `Is2D` falsch zurück, dann gibt sie falsch zurück.

## Wert

Ein Boolean. Wahr zeigt an, dass die Transformation eine 2D-Transformation ist, falsch, dass es sich um eine 3D-Transformation handelt.
