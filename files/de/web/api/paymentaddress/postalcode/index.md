Die schreibgeschützte **`postalCode`**-Eigenschaft des [`PaymentAddress`](/de/docs/Web/API/PaymentAddress)-Interfaces gibt eine Zeichenkette zurück, die einen von einer Jurisdiktion für die Postzustellung verwendeten Code enthält, zum Beispiel die [PLZ](https://en.wikipedia.org/wiki/ZIP_Code) in den Vereinigten Staaten oder die [Postleitzahl](https://en.wikipedia.org/wiki/Postal_Index_Number) in Indien.

## Wert

Eine Zeichenkette, die den Postleitzahlanteil der Adresse enthält. Eine Postleitzahl ist eine Zeichenkette (entweder numerisch oder alphanumerisch), die von einem Postdienst verwendet wird, um die Postzustellung zu optimieren.

Verschiedene Länder verwenden hierfür unterschiedliche Begriffe. In den meisten Teilen der Welt wird es als "Post Code" oder "Postal Code" bezeichnet. In den Vereinigten Staaten wird der ZIP-Code verwendet. Indien verwendet PIN-Codes.
