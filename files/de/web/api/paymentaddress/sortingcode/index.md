Die **`sortingCode`**-Eigenschaft des
[`PaymentAddress`](/de/docs/Web/API/PaymentAddress)-Interfaces ist schreibgeschützt und gibt eine Zeichenkette zurück, die einen postalischen Sortiercode enthält, wie er in Frankreich verwendet wird.

## Wert

Eine Zeichenkette, die den Sortiercode-Teil der Adresse enthält.
