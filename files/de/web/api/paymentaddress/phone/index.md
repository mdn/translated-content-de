Die schreibgeschützte **`phone`**-Eigenschaft des [`PaymentAddress`](/de/docs/Web/API/PaymentAddress)-Interfaces gibt einen String zurück, der die Telefonnummer des Empfängers oder der Kontaktperson enthält.

## Wert

Ein String, der die Telefonnummer des Empfängers der Lieferung oder der verantwortlichen Partei für die Zahlung enthält. Wenn keine Telefonnummer verfügbar ist, ist dieser Wert ein leerer String.
