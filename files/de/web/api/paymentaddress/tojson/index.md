Die **`toJSON()`**-Methode der [`PaymentAddress`](/de/docs/Web/API/PaymentAddress)-Schnittstelle ist ein standardmäßiger Serializer, der eine JSON-Darstellung der Eigenschaften des PaymentAddress-Objekts zurückgibt.

## Syntax

```js-nolint
toJSON()
```

### Parameter

Keine.

### Rückgabewert

Ein JSON-Objekt.
