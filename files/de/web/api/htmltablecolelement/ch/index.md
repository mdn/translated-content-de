{{APIRef("HTML DOM")}}

Die **`ch`**-Eigenschaft der [`HTMLTableColElement`](/de/docs/Web/API/HTMLTableColElement)-Schnittstelle hat keine Funktion. Sie spiegelt das `char`-Attribut des {{HTMLElement("col")}}-Elements wider.

> [!NOTE]
> Diese Eigenschaft wurde entworfen, um die Fähigkeit zu unterstützen, Tabellenzellinhalte an einem bestimmten Zeichen (typischerweise dem Dezimalpunkt) auszurichten, wurde jedoch nie von den Browsern implementiert.
>
> Um eine solche Ausrichtung zu erreichen, achten Sie auf die Unterstützung eines Zeichenfolgenwertes mit der CSS-Eigenschaft {{cssxref("text-align")}}.

## Wert

Ein einzelnes Zeichen.
