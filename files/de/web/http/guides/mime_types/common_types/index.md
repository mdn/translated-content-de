Dieses Thema listet die gängigsten MIME-Typen mit den zugehörigen Dokumenttypen auf, sortiert nach ihren üblichen Dateiendungen.

Die folgenden beiden MIME-Typen sind die Standardtypen:

- `text/plain` ist der Standardwert für Textdateien. Eine Textdatei sollte für Menschen lesbar sein und darf keine Binärdaten enthalten.
- `application/octet-stream` ist der Standardwert für alle anderen Fälle. Für einen unbekannten Dateityp sollte dieser Typ verwendet werden. Wenn Browser eine Ressource aufrufen, die mit diesem Typ bereitgestellt wird, laden sie sie in der Regel herunter, statt sie als Seite anzuzeigen. So wird vermieden, dass Skripte im Origin der bereitstellenden Website ausgeführt werden. Solche Ressourcen können jedoch weiterhin in anderen Kontexten verwendet werden, unter anderem als JavaScript, wenn ein klassisches {{HTMLElement("script")}}-Element auf sie verweist. Um dieses Verhalten zu verhindern, senden Sie [`X-Content-Type-Options: nosniff`](/de/docs/Web/HTTP/Reference/Headers/X-Content-Type-Options).

IANA ist das offizielle Register für MIME-Medientypen und führt eine [Liste aller offiziellen MIME-Typen](https://www.iana.org/assignments/media-types). Diese Tabelle enthält wichtige MIME-Typen für das Web:
