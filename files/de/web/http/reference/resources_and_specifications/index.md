HTTP wurde erstmals in den frühen 1990er Jahren spezifiziert. Mit Blick auf Erweiterbarkeit entworfen, hat es im Laufe der Jahre zahlreiche Ergänzungen erfahren; dies führte dazu, dass seine Spezifikation auf zahlreiche Spezifikationsdokumente verteilt ist (inmitten experimenteller aufgegebener Erweiterungen). Diese Seite listet relevante Ressourcen über HTTP auf.
