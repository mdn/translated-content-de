Wir sind eine offene Gemeinschaft aus Entwicklern, technischen Autoren und Lernenden, die unabhängig von Marke, Browser oder Plattform Ressourcen für ein besseres Web schaffen.
Alle können mitwirken, und jeder Beitrag erreicht Millionen von Lesern.
Erfahren Sie, wie Sie mitwirken und Innovationen im Open Web vorantreiben können.

## Wie kann ich helfen?

Je nach Ihren Fähigkeiten und Interessen gibt es verschiedene Möglichkeiten, zu MDN beizutragen. Deshalb finden Sie zu jeder Aufgabe eine kurze Beschreibung und eine ungefähre Angabe, wie viel Zeit diese Art von Aufgabe normalerweise in Anspruch nimmt.
Wenn Sie unsicher sind, was Sie tun können, fragen Sie jederzeit über einen [unserer Kommunikationskanäle](/de/docs/MDN/Community/Communication_channels) nach Hilfe.

Wir haben eine [Aufgabenübersicht für Mitwirkende](https://github.com/orgs/mdn/projects/25/views/1) erstellt, damit Sie Möglichkeiten zur Mitarbeit finden, die das Projekt spürbar voranbringen. Die Übersicht bietet einen allgemeinen Überblick sowie separate Ansichten für bestimmte Arten von Beiträgen.
Beachten Sie, dass unser kleines, aber schlagkräftiges Dokumentationsteam dieses Repository betreut.
Damit uns genügend Zeit für diese Arbeit bleibt, werden themenfremde Diskussionen geschlossen.

## Was benötige ich für den Einstieg?

Um mitwirken zu können, benötigen Sie ein GitHub-Konto.
Falls Sie noch keines haben, [registrieren Sie sich](https://github.com/signup), bevor Sie fortfahren.
Wenn Sie GitHub noch nicht kennen, empfehlen wir Ihnen die folgenden kostenlosen Kurse und Materialien von GitHub, die Sie in Ihrem eigenen Tempo durcharbeiten können. Mit diesem Wissen können Sie sich auf Ihre Beiträge konzentrieren, ohne gleichzeitig ein neues Werkzeug erlernen zu müssen.

- [Einführung in GitHub](https://github.com/skills/introduction-to-github)
- [Git einrichten](https://docs.github.com/en/get-started/git-basics/set-up-git)
- [GitHub-Workflow](https://docs.github.com/en/get-started/using-github/github-flow)
- [Markdown verwenden](https://github.com/skills/communicate-using-markdown)

> [!NOTE]
> Der Kurs „Einführung in GitHub“ sollte für den Einstieg ausreichen.
> Sie können zunächst fortfahren und später zu den anderen Dokumenten zurückkehren.

Außerdem empfehlen wir Ihnen, die folgenden Lernmaterialien zu lesen:

- [Grundlegende Umgangsformen in Open-Source-Projekten](/de/docs/MDN/Community/Open_source_etiquette): Wenn Sie noch nie zu einem Open-Source-Projekt beigetragen haben, empfehlen wir Ihnen dieses Dokument.
- [Webentwicklung lernen](/de/docs/Learn_web_development): Wenn HTML, CSS und JavaScript neu für Sie sind, finden Sie hier hilfreiche Inhalte für den Einstieg.
- [Ausführliche Einführung in die Zusammenarbeit mit Pull Requests](https://docs.github.com/en/pull-requests)

Für einige Beiträge, bei denen Sie Texte verfassen, sind angemessene Englischkenntnisse erforderlich.
Machen Sie sich jedoch keine Sorgen, wenn Ihre Grammatik nicht perfekt ist: Ein Team prüft Ihre Texte und hilft Ihnen, sie zu verbessern.
Wir brauchen Ihr technisches Fachwissen und helfen Ihnen dabei, Ihre englischen Texte zu überarbeiten.

## Eine Aufgabe auswählen und loslegen

Wenn Sie sich für eine Art von Aufgabe entschieden haben, besuchen Sie die [Aufgabenübersicht für Mitwirkende](https://github.com/orgs/mdn/projects/25/views/1) und wählen Sie ein Issue aus. Teilen Sie uns Ihre Wahl mit, indem Sie das Issue kommentieren und dabei das Team `@mdn/community` erwähnen.
Jemand aus dem Team wird Ihnen mit Anmerkungen, Tipps oder Hilfestellungen antworten.

Stellen Sie sicher, dass nicht bereits jemand an der Aufgabe arbeitet – doppelte oder vergebliche Arbeit kann frustrierend sein.
Fragen Sie im Zweifelsfall im Issue nach.

MDN Web Docs ist ein komplexes Projekt mit vielen Komponenten. Es lohnt sich, sich mit den [verschiedenen Code-Repositories](/de/docs/MDN/Community/Our_repositories) vertraut zu machen.

## Möglichkeiten zur Mitarbeit

Sie können auf folgende Weise zu MDN Web Docs beitragen:

- [An geeigneten Issues für den Einstieg arbeiten](https://github.com/orgs/mdn/projects/25/views/1)
- [Pull Requests prüfen](/de/docs/MDN/Community/Pull_requests)
- [Anfängern in unserer Community helfen](/de/docs/MDN/Community)
- [Bei der Übersetzung von MDN Web Docs helfen](/de/docs/MDN/Community/Translated_content)
- [Bei der Behebung bekannter Backend-Probleme helfen](https://github.com/mdn/rari/issues) und [bei der Behebung bekannter Frontend-Probleme helfen](https://github.com/mdn/fred/issues)
- [Helfen, die Daten zur Browser-Kompatibilität aktuell zu halten](https://github.com/mdn/browser-compat-data)

## Beiträge

Mit Ihrer Mitarbeit erklären Sie sich damit einverstanden, Ihre Beiträge unter der [Attribution-ShareAlike-Lizenz](https://creativecommons.org/licenses/by-sa/4.0/) verfügbar zu machen (oder unter einer anderen Lizenz, die bereits für die von Ihnen bearbeitete Seite festgelegt wurde).
Codebeispiele sind darüber hinaus unter [Creative Commons CC-0](https://wiki.creativecommons.org/wiki/CC0) verfügbar (einer Freigabe für die Gemeinfreiheit).

Sie sind für Ihre Beiträge verantwortlich. Prüfen Sie Ihre Arbeit vor dem Einreichen und stellen Sie sicher, dass Sie jede Änderung erklären können.

Achten Sie darauf, dass sämtliche Inhalte technisch korrekt sind und dass Sie berechtigt sind, sie unter diesen Bedingungen zu lizenzieren.

Wenn Sie Fragen oder Bedenken zu den hier behandelten Themen haben, [kontaktieren Sie uns](/de/docs/MDN/Community/Communication_channels).
