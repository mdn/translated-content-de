Wir sind eine offene Gemeinschaft aus Entwicklern, technischen Redakteuren und Lernenden, die Ressourcen für ein besseres Web erstellen – unabhängig von Marke, Browser oder Plattform.
Jede und jeder kann beitragen, und jede Person, die einen Beitrag leistet, hat Einfluss auf Millionen von Lesern.
Erfahren Sie, wie Sie beitragen und Innovationen im Open Web vorantreiben können.

## Wie kann ich helfen?

Je nach Ihren Fähigkeiten und Interessen gibt es mehrere Möglichkeiten, zu MDN beizutragen. Daher stellen wir zu jeder Aufgabe eine kurze Beschreibung sowie eine ungefähre Zeitangabe bereit, die der jeweilige Aufgabentyp normalerweise benötigt.
Wenn Sie unsicher sind, was Sie tun sollen, können Sie jederzeit in einem unserer [Kommunikationskanäle](/de/docs/MDN/Community/Communication_channels) um Hilfe bitten.

Wir haben ein [Aufgabenboard für Mitwirkende](https://github.com/orgs/mdn/projects/25/views/1) erstellt, das Ihnen hilft, Möglichkeiten zur Mitarbeit zu finden, die einen bedeutenden Einfluss auf das Projekt haben. Das Board bietet eine Übersicht sowie separate Ansichten für bestimmte Arten von Beiträgen.
Beachten Sie, dass unser kleines, aber leistungsstarkes Dokumentationsteam dieses Repository betreut.
Um unsere Kapazitäten zu schonen, werden themenfremde Diskussionen geschlossen.

## Was brauche ich für den Einstieg?

Um beizutragen, benötigen Sie ein GitHub-Konto.
Falls Sie noch keines haben, [registrieren Sie sich](https://github.com/signup) für ein Konto, bevor Sie fortfahren.
Wenn Sie neu bei GitHub sind, empfehlen wir Ihnen, die folgenden kostenlosen Kurse zum Selbststudium und Lesematerialien von GitHub zu nutzen. Mit diesem Wissen können Sie sich auf Ihre Beiträge konzentrieren, ohne gleichzeitig ein neues Tool lernen zu müssen.

- [Einführung in GitHub](https://github.com/skills/introduction-to-github)
- [Git einrichten](https://docs.github.com/en/get-started/git-basics/set-up-git)
- [GitHub-Workflow](https://docs.github.com/en/get-started/using-github/github-flow)
- [Markdown verwenden](https://github.com/skills/communicate-using-markdown)

> [!NOTE]
> Der Kurs „Introduction to GitHub“ sollte ausreichen, um Ihnen den Einstieg zu erleichtern.
> Sie können gerne direkt weitermachen und später zu den anderen Dokumenten zurückkehren.

Wir empfehlen außerdem, die folgenden Lernmaterialien zu lesen:

- [Grundlegende Etikette für Open-Source-Projekte](/de/docs/MDN/Community/Open_source_etiquette): Wenn Sie noch nie zu einem Open-Source-Projekt beigetragen haben, empfehlen wir Ihnen, dieses Dokument zu lesen.
- [Webentwicklung lernen](/de/docs/Learn_web_development): Wenn Sie neu bei HTML, CSS und JavaScript sind, finden Sie bei uns großartige Inhalte, die Ihnen den Einstieg erleichtern.
- [Vertiefung der Zusammenarbeit mit Pull Requests](https://docs.github.com/en/pull-requests)

Einige Möglichkeiten zur Mitarbeit im Bereich Schreiben erfordern angemessene Englischkenntnisse.
Machen Sie sich jedoch keine Sorgen, wenn Ihre Grammatik nicht perfekt ist: Wir haben ein Team von Personen, das Ihre Texte überprüft und Ihnen hilft, sie zu verbessern.
Wir brauchen Ihre technische Fachkenntnis und helfen Ihnen dabei, Ihr Englisch zu überarbeiten.

## Auswahl einer Aufgabe und Einstieg

Sobald Sie sich entschieden haben, an welcher Art von Aufgabe Sie arbeiten möchten, besuchen Sie das [Aufgabenboard für Mitwirkende](https://github.com/orgs/mdn/projects/25/views/1), wählen Sie ein Issue aus und teilen Sie uns dies mit, indem Sie das Issue kommentieren und das Team `@mdn/community` markieren.
Jemand aus dem Team wird mit Kommentaren, Hinweisen oder Anleitung antworten.

Stellen Sie sicher, dass Sie nicht an etwas arbeiten, das bereits in Bearbeitung ist – es kann frustrierend sein, Arbeit zu duplizieren oder zu verlieren.
Fragen Sie im Zweifelsfall im Issue nach.

MDN Web Docs ist ein komplexes Projekt mit vielen beweglichen Teilen. Es ist sinnvoll, sich mit den [verschiedenen Code-Repositories](/de/docs/MDN/Community/Our_repositories) vertraut zu machen.

## Möglichkeiten zur Mitarbeit

Hier ist eine Liste der Möglichkeiten, wie Sie zu MDN Web Docs beitragen können:

- [An geeigneten ersten Issues arbeiten](https://github.com/orgs/mdn/projects/25/views/1)
- [Pull Requests überprüfen](/de/docs/MDN/Community/Pull_requests)
- [Anfängern in unserer Community helfen](/de/docs/MDN/Community)
- [Beim Übersetzen von MDN Web Docs helfen](/de/docs/MDN/Community/Translated_content)
- [Beim Beheben bekannter Backend-Probleme helfen](https://github.com/mdn/rari/issues) und [bekannter Frontend-Probleme](https://github.com/mdn/fred/issues)
- [Uns helfen, Browser-Kompatibilitätsdaten aktuell zu halten](https://github.com/mdn/browser-compat-data)

## Beiträge

Mit Ihrem Beitrag erklären Sie sich damit einverstanden, Ihre Beiträge unter der [Namensnennung-Weitergabe unter gleichen Bedingungen-Lizenz](https://creativecommons.org/licenses/by-sa/4.0/) verfügbar zu machen (oder unter einer alternativen Lizenz, die bereits auf der von Ihnen bearbeiteten Seite angegeben ist).
Darüber hinaus sind Codebeispiele unter [Creative Commons CC-0](https://wiki.creativecommons.org/wiki/CC0) verfügbar (einer Public-Domain-Widmung).

Wenn Sie Fragen oder Bedenken zu den hier behandelten Themen haben, [kontaktieren Sie uns](/de/docs/MDN/Community/Communication_channels).
