Diese Seite listet Abschnitte der MDN Web Docs auf, die ausgemustert wurden. Jeder Eintrag enthält einen Link zu den archivierten Inhalten im [MDN Museum Repository](https://github.com/mdn/museum) und zur GitHub-Issue oder Diskussion, in der die Entscheidung zur Ausmusterung getroffen wurde.

Für Details darüber, wie die Ausmusterung funktioniert, siehe den [Content-Ausmusterungsleitfaden](/de/docs/MDN/Writing_guidelines/Howto/Retiring_content).

## Ausgemusterte Abschnitte

### Canvas Raycaster

- **Ausgemustert:** Juni 2022
- **Archivierte Inhalte:** [museum/canvas-raycaster](https://github.com/mdn/museum/tree/main/canvas-raycaster)
- **Issue auf GitHub:** [Move canvas-raycaster into mdn/museum](https://github.com/mdn/mdn/issues/193)

Eine Canvas API Raycaster-Demo und ihre begleitende Dokumentationsseite. Die Inhalte wurden als Teil der Repository-Wartung in das Museum verschoben.

> [!NOTE]
> Diese Ausmusterung erfolgte vor dem [Content-Ausmusterungsleitfaden](/de/docs/MDN/Writing_guidelines/Howto/Retiring_content) Prozess. Es gibt keine Diskussion mehr.

### WebVR

- **Ausgemustert:** September 2022
- **Archiv im GitHub:** [museum/webvr](https://github.com/mdn/museum/tree/main/webvr)
- **PR auf GitHub:** [Import webvr tests](https://github.com/mdn/museum/pull/6)

Eine Sammlung von WebVR API-Testbeispielen, einschließlich grundlegender Anzeigeinformationen, Bühnenparameter, rohem WebGL, VR-Controller-Demos und einer A-Frame-Demo. Die WebVR API wurde zugunsten der [WebXR Device API](/de/docs/Web/API/WebXR_Device_API) veraltet.

> [!NOTE]
> Diese Ausmusterung erfolgte vor dem [Content-Ausmusterungsleitfaden](/de/docs/MDN/Writing_guidelines/Howto/Retiring_content) Prozess. Es gibt keine Diskussion mehr.

### Angular, Ember, Svelte und Vue JS Framework-Tutorials

- **Ausgemustert:** August 2026
- **Archivierte Inhalte:** [museum/learn_web_development/frameworks_libraries](https://github.com/mdn/museum/tree/main/learn_web_development/frameworks_libraries)
- **Diskussion:** [Removing the old and out-of-date JavaScript framework articles from Learn web development](https://github.com/orgs/mdn/discussions/827)
- **PR auf GitHub:** [Archive JS framework content](https://github.com/mdn/content/pull/45105)

Eine Reihe von Einsteigertutorials, die zeigen, wie man eine grundlegende Web-App mit den Frameworks Angular, Ember, Svelte und Vue erstellt.
