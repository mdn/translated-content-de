Die Inhalte von MDN Web Docs sind kostenlos verfügbar und stehen unter verschiedenen Open-Source-Lizenzen.

## Inhalte von MDN Web Docs verwenden

Dieser Abschnitt behandelt die Arten von Inhalten, die wir bereitstellen, sowie die Urheberrechte und Lizenzen, die für jeden Typ gelten, falls Sie Inhalte wiederverwenden möchten.

### Dokumentation

> [!NOTE]
> Die Inhalte auf MDN Web Docs wurden mit Beiträgen von Autorinnen und Autoren innerhalb und außerhalb von Mozilla erstellt. Sofern nicht anders angegeben, stehen die Inhalte unter den Bedingungen der [Creative-Commons-Lizenz Attribution-ShareAlike](https://creativecommons.org/licenses/by-sa/2.5/) (CC-BY-SA), v2.5 oder einer späteren Version.

Ihre Wiederverwendung der Inhalte hier wird unter derselben Lizenz wie die ursprünglichen Inhalte veröffentlicht – CC-BY-SA v2.5 oder einer späteren Version.
Bei der Wiederverwendung von Inhalten auf MDN Web Docs müssen Sie sicherstellen, dass dem Material sowie „Mozilla Contributors“ eine [Namensnennung](https://creativecommons.org/licenses/by/2.5/deed.en#ref-appropriate-credit) gegeben wird.
Eine gute Namensnennung umfasst den **Titel** des Dokuments mit einem Hyperlink (online) oder einer URL (im Druck) zur spezifischen Seite der verwendeten Inhalte sowie eine kurze Beschreibung aller von Ihnen vorgenommenen Änderungen.
Um beispielsweise eine Namensnennung für diese Seite bereitzustellen, können Sie schreiben:

> [„Namensnennungen und Urheberrechtslizenzierung“](/de/docs/MDN/Writing_guidelines/Attrib_copyright_license) von Mozilla Contributors, lizenziert unter [CC-BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/).

Sie können „Mozilla Contributors“ auch mit einer `contributors.txt`-Datei verlinken, auf die im Seitenfuß der von Ihnen referenzierten Seite verwiesen wird und die eine Liste der Autorinnen und Autoren enthält, sofern dies sinnvoll ist.
Weitere Details finden Sie unter [Empfohlene Praktiken für die Namensnennung](https://wiki.creativecommons.org/wiki/Recommended_practices_for_attribution).

### Codebeispiele

Codebeispiele, die am oder nach dem 20. August 2010 hinzugefügt wurden, sind [gemeinfrei unter CC0](https://creativecommons.org/publicdomain/zero/1.0/). Ein Lizenzhinweis ist nicht erforderlich, aber falls Sie einen benötigen, können Sie Folgendes verwenden: `Any copyright is dedicated to the Public Domain: https://creativecommons.org/publicdomain/zero/1.0/`

Codebeispiele, die vor dem 20. August 2010 hinzugefügt wurden, stehen unter der [MIT-Lizenz](https://opensource.org/license/mit); Sie sollten die folgenden Informationen zur Namensnennung in die MIT-Vorlage einfügen: „© \<Datum der letzten Überarbeitung der Wiki-Seite> \<Name der Person, die es ins Wiki eingefügt hat>“.

### Ihre Beiträge

Wenn Sie zu MDN Web Docs beitragen möchten, stimmen Sie zu, dass Ihre Dokumentation unter der Attribution-ShareAlike-Lizenz verfügbar ist (oder gelegentlich unter einer alternativen Lizenz, die bereits auf der von Ihnen bearbeiteten Seite angegeben ist) und dass Ihre Codebeispiele unter [Creative Commons CC-0](https://creativecommons.org/publicdomain/zero/1.0/) (einer Public-Domain-Widmung) verfügbar sind.

> [!WARNING]
> Es dürfen keine neuen Seiten unter alternativen Lizenzen erstellt werden.

**Das Urheberrecht an beigetragenen Materialien verbleibt bei der Autorin oder dem Autor, sofern diese Person es nicht jemand anderem überträgt.**

Wenn Sie Fragen oder Bedenken zu den hier behandelten Themen haben, kontaktieren Sie bitte das [MDN-Web-Docs-Team](/de/docs/MDN/Community/Communication_channels).

### Logos, Marken, Dienstleistungsmarken und Wortmarken

Die Rechte an den Logos, Marken und Dienstleistungsmarken der Mozilla Foundation sowie am Erscheinungsbild dieser Website sind nicht unter der Creative-Commons-Lizenz lizenziert. Soweit es sich um urheberrechtlich geschützte Werke handelt (wie Logos und grafisches Design), sind sie nicht in dem Werk enthalten, das unter diesen Bedingungen lizenziert ist. Wenn Sie den Text von Dokumenten verwenden und auch eines dieser Rechte nutzen möchten oder wenn Sie weitere Fragen zur Einhaltung unserer Lizenzbedingungen für diese Sammlung haben, sollten Sie die Mozilla Foundation hier kontaktieren: [licensing@mozilla.org](mailto:licensing@mozilla.org).

## Inhalte von anderen Quellen auf MDN Web Docs verwenden

Im Allgemeinen befürworten wir es nicht, Inhalte aus anderen Quellen zu kopieren und auf MDN zu veröffentlichen.
MDN sollte nach Möglichkeit aus originalen Inhalten bestehen.
Wenn wir einen Pull Request erhalten und feststellen, dass er plagiierten Inhalt enthält, werden wir ihn schließen und die einreichende Person bitten, die Änderung erneut einzureichen, nachdem der Inhalt mit eigenen Worten umgeschrieben wurde.

### Ihre Inhalte auf MDN wiederverwenden oder erneut veröffentlichen

> [!NOTE]
> Sofern es keinen guten Grund gibt, die Inhalte erneut zu veröffentlichen, werden wir wahrscheinlich „nein“ sagen.
> Die Entscheidung des MDN-Redaktionsteams ist endgültig.

Wenn jemand MDN einen Artikel spenden möchte, den diese Person zuvor in ihrem Blog veröffentlicht hat, oder wenn es sinnvoll ist, ein komplexes Referenzblatt auf MDN zu kopieren, kann eine erneute Veröffentlichung gerechtfertigt sein. Besprechen Sie Ihren Plan in diesen Fällen vorab mit dem MDN-Team:

- [Erstellen Sie ein GitHub-Issue](https://github.com/mdn/mdn/issues/new/choose), in dem Sie Ihre Absicht erläutern.
  - Beschreiben Sie, was Sie kopieren oder erneut veröffentlichen möchten.
  - Geben Sie eine URL zur Ressource an.
  - Erläutern Sie, warum Sie dies für angemessen halten.

**Wenn der Inhalt unter einer geschlossenen Lizenz veröffentlicht ist:**

- Wenn Sie die Rechte an dem Inhalt besitzen, geben Sie dies sowie Ihre ausdrückliche Zustimmung an, ihn auf MDN erneut zu veröffentlichen.
- Wenn Sie die Rechte an dem Inhalt nicht besitzen, beziehen Sie die Autorin, den Autor oder den Verlag nach Möglichkeit in das Issue ein oder geben Sie Details dazu an, wie diese kontaktiert werden können, damit wir sie um Erlaubnis bitten können, den Inhalt erneut zu veröffentlichen.

**Wenn der Inhalt unter einer offenen Lizenz veröffentlicht ist:**

- Geben Sie an, um welche Lizenz es sich handelt, und verlinken Sie auf die Lizenz, damit wir prüfen können, ob sie mit der [MDN-Lizenz](https://github.com/mdn/content/blob/main/LICENSE.md) kompatibel ist.

## Verlinken auf MDN-Web-Docs-Artikel

Wir erhalten regelmäßig Fragen von Nutzern dazu, wie auf MDN Web Docs verlinkt werden kann und ob dies überhaupt erlaubt ist. Die kurze Antwort lautet: **Ja, Sie können auf MDN Web Docs verlinken!** Der Hypertext-Link ist nicht nur das Wesen des Webs, sondern auch eine Möglichkeit, Ihre Nutzer auf wertvolle Ressourcen hinzuweisen und Vertrauen in die Arbeit unserer Community zu zeigen.
