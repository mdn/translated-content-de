Die Inhalte der MDN Web Docs sind kostenlos verfügbar und stehen unter verschiedenen Open-Source-Lizenzen.

## Verwendung von Inhalten der MDN Web Docs

Dieser Abschnitt erläutert, welche Arten von Inhalten wir bereitstellen und welche Urheberrechte und Lizenzen jeweils gelten, wenn Sie diese Inhalte weiterverwenden möchten.

### Dokumentation

> [!NOTE]
> Die Inhalte der MDN Web Docs wurden mit Beiträgen von Autorinnen und Autoren innerhalb und außerhalb von Mozilla erstellt. Sofern nicht anders angegeben, stehen die Inhalte unter den Bedingungen der [Creative-Commons-Lizenz „Namensnennung – Weitergabe unter gleichen Bedingungen“](https://creativecommons.org/licenses/by-sa/2.5/) (CC-BY-SA), Version 2.5 oder einer späteren Version.

Wenn Sie die Inhalte weiterverwenden, müssen Sie sie unter derselben Lizenz wie die Originalinhalte veröffentlichen – CC-BY-SA 2.5 oder einer späteren Version.
Bei der Weiterverwendung von Inhalten der MDN Web Docs müssen Sie sowohl das Material als auch „Mozilla Contributors“ [angemessen nennen](https://creativecommons.org/licenses/by/2.5/deed.en#ref-appropriate-credit).
Eine gute Namensnennung umfasst den **Titel** des Dokuments mit einem Hyperlink (online) oder einer URL (in gedruckten Medien) zur jeweiligen Quellseite sowie eine kurze Beschreibung aller von Ihnen vorgenommenen Änderungen.
Für diese Seite könnten Sie beispielsweise folgende Namensnennung verwenden:

> [„Namensnennung und Urheberrechtslizenzen“](/de/docs/MDN/Writing_guidelines/Attrib_copyright_license) von Mozilla Contributors, lizenziert unter [CC-BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/).

Falls sinnvoll, können Sie „Mozilla Contributors“ auch mit der Datei `contributors.txt` verlinken, die in der Fußzeile der betreffenden Seite verlinkt ist und eine Liste der Autorinnen und Autoren enthält.
Weitere Informationen finden Sie unter [Empfohlene Vorgehensweisen für die Namensnennung](https://wiki.creativecommons.org/wiki/Recommended_practices_for_attribution).

### Codebeispiele

Codebeispiele, die am oder nach dem 20. August 2010 hinzugefügt wurden, sind gemäß [CC0 gemeinfrei](https://creativecommons.org/publicdomain/zero/1.0/). Ein Lizenzhinweis ist nicht erforderlich. Falls Sie dennoch einen benötigen, können Sie Folgendes verwenden: `Any copyright is dedicated to the Public Domain: https://creativecommons.org/publicdomain/zero/1.0/`

Codebeispiele, die vor dem 20. August 2010 hinzugefügt wurden, stehen unter der [MIT-Lizenz](https://opensource.org/license/mit). Fügen Sie die folgenden Angaben zur Namensnennung in die MIT-Vorlage ein: „© \<Datum der letzten Überarbeitung der Wiki-Seite> \<Name der Person, die das Beispiel in das Wiki eingefügt hat>“.

### Ihre Beiträge

Wenn Sie zu den MDN Web Docs beitragen möchten, erklären Sie sich damit einverstanden, dass Ihre Dokumentationsbeiträge unter der Lizenz „Namensnennung – Weitergabe unter gleichen Bedingungen“ verfügbar sind (oder gelegentlich unter einer anderen Lizenz, die bereits für die von Ihnen bearbeitete Seite festgelegt wurde) und dass Ihre Codebeispiele unter [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/) verfügbar sind (als Widmung an die Gemeinfreiheit).

> [!WARNING]
> Neue Seiten dürfen nicht unter anderen Lizenzen erstellt werden.

**Das Urheberrecht an beigetragenen Materialien verbleibt bei den jeweiligen Autorinnen und Autoren, sofern sie es nicht auf jemand anderen übertragen.**

Wenn Sie Fragen oder Bedenken zu einem der hier behandelten Themen haben, wenden Sie sich bitte an das [MDN-Web-Docs-Team](/de/docs/MDN/Community/Communication_channels).

### Logos, Marken, Dienstleistungsmarken und Wortmarken

Die Rechte an den Logos, Marken und Dienstleistungsmarken der Mozilla Foundation sowie am Erscheinungsbild dieser Website werden nicht unter der Creative-Commons-Lizenz lizenziert. Soweit es sich dabei um urheberrechtlich geschützte Werke handelt (wie Logos und grafische Gestaltungen), gehören sie nicht zu den Werken, die unter diesen Bedingungen lizenziert sind. Wenn Sie Texte aus den Dokumenten verwenden und darüber hinaus eines dieser Rechte nutzen möchten oder andere Fragen zur Einhaltung unserer Lizenzbedingungen für diese Sammlung haben, wenden Sie sich bitte an die Mozilla Foundation unter [licensing@mozilla.org](mailto:licensing@mozilla.org).

## Verwendung von Inhalten aus anderen Quellen

Wir billigen es nicht, Inhalte aus anderen Quellen zu kopieren und auf MDN zu veröffentlichen.
MDN sollte aus Originalinhalten bestehen, mit Ausnahme der Fälle, die unter [Wiederverwendung oder erneute Veröffentlichung Ihrer Inhalte auf MDN](#wiederverwendung_oder_erneute_veröffentlichung_ihrer_inhalte_auf_mdn) beschrieben sind.
Seien Sie vorsichtig mit Werkzeugen, die Material aus anderen Quellen ohne Namensnennung reproduzieren können.
Sie müssen berechtigt sein, alles, was Sie beitragen, unter den auf dieser Seite beschriebenen Bedingungen zu lizenzieren.
Wenn wir einen Pull Request erhalten und feststellen, dass er plagiierte Inhalte enthält, schließen wir ihn und bitten die einreichende Person, die Änderung mit in eigenen Worten neu formulierten Inhalten erneut einzureichen.

### Wiederverwendung oder erneute Veröffentlichung Ihrer Inhalte auf MDN

> [!NOTE]
> Sofern es keinen guten Grund für eine erneute Veröffentlichung der Inhalte gibt, werden wir wahrscheinlich „Nein“ sagen.
> Die Entscheidung des MDN-Redaktionsteams ist endgültig.

Wenn jemand einen zuvor auf dem eigenen Blog veröffentlichten Artikel an MDN spenden möchte oder es sinnvoll erscheint, ein komplexes Referenzdokument auf MDN zu übernehmen, kann eine erneute Veröffentlichung gerechtfertigt sein. Besprechen Sie Ihren Plan in solchen Fällen vorab mit dem MDN-Team:

- [Erstellen Sie ein GitHub-Issue](https://github.com/mdn/mdn/issues/new/choose), in dem Sie Ihr Vorhaben erläutern.
  - Beschreiben Sie, was Sie kopieren oder erneut veröffentlichen möchten.
  - Geben Sie eine URL zur Quelle an.
  - Erläutern Sie, warum Sie das für angemessen halten.

**Wenn die Inhalte unter einer nicht offenen Lizenz veröffentlicht wurden:**

- Wenn Sie die Rechte an den Inhalten besitzen, geben Sie dies an und erklären Sie ausdrücklich Ihr Einverständnis mit der erneuten Veröffentlichung auf MDN.
- Wenn Sie die Rechte an den Inhalten nicht besitzen, beziehen Sie die Autorin oder den Autor beziehungsweise den Verlag nach Möglichkeit in das Issue ein. Geben Sie andernfalls an, wie wir Kontakt aufnehmen können, damit wir um Erlaubnis zur erneuten Veröffentlichung der Inhalte bitten können.

**Wenn die Inhalte unter einer offenen Lizenz veröffentlicht wurden:**

- Geben Sie an, um welche Lizenz es sich handelt, und verlinken Sie sie, damit wir prüfen können, ob sie mit der [MDN-Lizenz](https://github.com/mdn/content/blob/main/LICENSE.md) vereinbar ist.

## Verlinkung auf Artikel der MDN Web Docs

Wir erhalten regelmäßig Fragen dazu, wie man auf die MDN Web Docs verlinkt und ob das überhaupt erlaubt ist. Die kurze Antwort lautet: **Ja, Sie dürfen auf die MDN Web Docs verlinken!** Hyperlinks sind nicht nur das Wesen des Webs. Sie ermöglichen es Ihnen auch, Ihre Nutzerinnen und Nutzer auf wertvolle Ressourcen hinzuweisen, und zeigen Vertrauen in die Arbeit unserer Community.
